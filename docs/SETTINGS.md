# 设置界面（1.8.0）

双击通知区域的 ClearDesk 图标打开设置。窗口采用浅色卡片和柔和渐变侧栏，分为六类：

| 分类 | 内容 |
| --- | --- |
| 通用 | 开机启动、桌面图标隐藏、空闲延迟、透明任务栏和窗口动画 |
| 桌面收纳 | 新建收纳格、恢复收纳格及操作说明 |
| Dock 栏 | 启用 Dock、图标尺寸、打开启动台 |
| 音乐组件 | 显示音乐组件、自动或指定播放器 |
| 外观与材质 | Dock 玻璃／实时磨砂、桌面组件开关（含 2.2.0 的待办清单、倒计时 / 番茄钟、日程、剪贴板历史、网速流量、快捷启动、图片相册、日出日落 + 空气质量）、天气自动定位与联网、使用 Windows 定位、所在地与重新定位、手动选择区县 |
| 关于 | 版本、维护者、软件更新（检查更新、自动检查、更新源）、配置目录、退出并恢复 |

左上搜索会查找所有分类。清空搜索或点击分类恢复正常页面；切换分类不会丢失已调整的值。

设置沿用原来的本机配置，修改会保存。启动项立即生效；双击图标、任务栏与动画开关沿用原来的即时应用行为。组件开关、尺寸、音乐来源和材质调整后点击“应用设置”更新桌面组件。

底部可恢复桌面图标、收起到托盘或应用设置。右上角关闭仅关闭设置窗口，ClearDesk 继续运行；退出整个程序请使用“关于 → 退出并恢复”或托盘退出入口。

窗口可缩放，较小尺寸下内容区域滚动，底部操作栏始终可见。控件支持键盘焦点和无障碍名称。

侧栏使用本地浅蓝渐变，保证阅读对比；桌面 Dock 的实时磨砂仍由原有 Windows 合成器实现。此次设置窗口重做不改变音乐客户端兼容范围。
