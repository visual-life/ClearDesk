# 开发说明

## 目录

| 目录 | 内容 |
| --- | --- |
| `src/` | 应用入口、桌面组件、Dock、启动台及 Windows 接口 |
| `tests/` | 桌面回归、独立窗口夹具与合成性能测试 |
| `assets/` | 图标 PNG 与多尺寸 ICO |
| `config/` | Windows manifest 与 .NET 运行时配置 |
| `scripts/` | 依赖准备、测试运行器及编译器校验值 |
| `third_party/` | 农历源代码和可选组件的许可证、配置及摘要 |
| `dist/` | 本地编译产物，Git 忽略 |
| `artifacts/` | 隔离的测试程序、测试配置和结果，Git 忽略 |

当前项目保持单一 C# 编译入口，`build.ps1` 直接调用 Roslyn。测试代码与程序一起编译，通过显式命令行参数运行，普通启动不执行测试。

## 验证范围

`Self` 验证配置序列化、农历、天气映射和基本 Windows 接口。非交互式环境可能无法发现桌面或注册钩子，日志会标注信息或限制。

`Regression` 验证收纳布局、滚动、材质切换、Dock 显隐、窗口生命周期、固定／取消固定、启动台透明和外部点击等。结果依赖本机桌面引用数量，不能用固定 PASS 数量作为跨机器标准。

`PopupBenchmark` 连续打开启动台，记录打开调用、首次渲染回调、布局稳定状态及渲染回调间隔。它使用测试模式，排除了全局外部点击监听；不是端到端用户体验或显示帧率测试。

交互回归应在单独的 Windows 桌面会话进行。测试会启动并关闭自有夹具窗口，不关闭用户应用。测试目录包含本机路径和图标引用，不能提交到 Git。

## 可选任务栏组件

首次准备可联网下载官方固定版本；离线准备允许传入完整发行包的 `taskbar` 目录。两条路径都验证 EXE/DLL 和上游源码压缩包摘要，并保留 GPL 许可证。不要修改摘要来掩盖未知来源的组件替换。
