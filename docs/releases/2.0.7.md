# ClearDesk 2.0.7 发布说明

发布日期：2026-10-23

## 组件自由调整宽高

此前除收纳格和便签外，组件只能等比放大缩小。2.0.7 起，时钟、性能、日历、黄历、天气、音乐（含歌词）、快捷控制都可以分别调整宽度和高度：

- 鼠标悬停在组件上，拖动**右边缘**调宽、拖动**下边缘**调高、拖动**右下角**同时调整。
- 最小为默认尺寸的 60%，最大为默认尺寸的 4 倍。
- 锁定或收起的组件不能调整（与移动一致）。
- 调整时显示磁吸辅助线：右边 / 下边可贴齐其他组件和屏幕（工作区）边缘，或与其他组件等宽 / 等高（虚线尺寸标注）；按住 Alt 可暂时关闭贴齐。
- 每个组件的尺寸单独保存。

## 响应式排版

文字和控件只按宽、高中**较小**的比例放大（60%–250%），保证内容不溢出；多余的空间交给布局重新排版：

| 组件 | 加宽 / 加高后的变化 |
|---|---|
| 音乐 | 开启歌词时歌词卡片随高度变高，显示当前句和更多后续歌词行（每约 22 像素多一行） |
| 天气 | 高度多出约 70 像素后显示多日预报卡片（今天起 3–7 天，越宽天数越多） |
| 时钟 | 文字按比例适配，内容在组件中居中 |
| 日历 / 黄历 | 文字按比例适配，多出的高度让内容居中 |
| 性能 | CPU / GPU / 内存 / 网络四格随宽高铺开 |
| 快捷控制 | 按钮和滑块随宽度加宽，内容垂直居中 |

## 恢复默认大小

- 右键菜单的「调整大小」百分比子菜单改为「恢复默认大小」，自定义过尺寸时可用。
- 组件管理中的「重置大小」同样清除自定义宽高。

## 兼容与迁移

- 2.0.5 / 2.0.6 中按比例缩放过的组件，首次启动时自动换算成对应的宽高（例如 125% → 默认宽高 × 1.25），外观不变。
- 天气请求在同一次 Open-Meteo 调用中附带 7 日预报；预报解析失败不影响当前天气显示。
- 收纳格、便签、Dock、启动台的尺寸方式不变。
