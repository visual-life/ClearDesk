# ClearDesk 2.0.5

发布日期：2026-10-22。维护者：visual-life。

## 变更

- 新增“顶部任务栏自动隐藏”（设置 → 任务栏与窗口，默认关闭）：
  - Windows 11 把任务栏放到屏幕顶部后，系统自带的“自动隐藏任务栏”不生效。开启此项后由 ClearDesk 收起顶部任务栏（含其他显示器上的副任务栏），并把任务栏原先占用的那一条区域还给应用，最大化窗口可以铺满整个屏幕。
  - 鼠标停在屏幕最上边缘约 0.15 秒，任务栏从屏幕上边缘向下平滑展开（约 0.18 秒，缓动）；离开任务栏约 0.5 秒后向上平滑收起。打开开始菜单（含按 Win 键）、搜索、托盘溢出区、快速设置、跳转列表或右键菜单时任务栏保持显示。
  - 全屏应用（游戏、视频全屏）在前台时，碰到上边缘不会唤出任务栏。
  - 资源管理器重启、显示器/分辨率/缩放变化后自动重新接管；任务栏被移回底部等位置时，此功能自动停用。
  - 关闭开关或退出 ClearDesk 时立即恢复任务栏位置和工作区；ClearDesk 意外结束时，守护进程同样会恢复任务栏。
- 所有桌面组件都可以调整大小：
  - 时钟、性能、日历、黄历、天气、音乐/歌词、快捷控制：鼠标悬停时右下角出现缩放手柄，拖动即可按比例放大或缩小（60%–250%），文字和图标保持清晰；也可以右键 → “调整大小”选择 75%/100%/125%/150%/175%/200%。
  - 收纳格、便签：继续拖动边缘或右下角自由调整宽高。
  - 锁定位置的组件不能调整大小（右键“调整大小”变灰，手柄不显示）；尺寸按组件分别保存，磁吸对齐按新尺寸计算。
  - 设置 → 组件管理：调整过大小的组件多了“重置大小”按钮，一键恢复 100%。
- 版本号统一为 2.0.5。

## 说明

- 任务栏不在顶部时此开关不起作用；底部任务栏请使用 Windows 自带的“自动隐藏任务栏”。
- 资源管理器偶尔会自行重新占用顶部区域，ClearDesk 会在几十毫秒内收回，最大化窗口可能瞬间上下跳动一次。
- 按比例缩放的组件是整体放大缩小（含边距），不会重新排版。
- 完整功能见 [2.0.4](2.0.4.md) 更新说明。
