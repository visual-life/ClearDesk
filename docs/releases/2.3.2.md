# ClearDesk 2.3.2

- 修复 Dock「距屏幕底部距离」设为 0 仍然悬在屏幕底边上方的问题（任务栏隐藏时）。
  - 根因有两个：
    1. Dock 的底边按 Windows 工作区（SystemParameters.WorkArea）的底边计算，而工作区在「完全隐藏任务栏」或任务栏被收起之后仍可能保留任务栏的位置——Dock 只在启动、重建或改设置时才算一次位置，完全隐藏任务栏生效（或工作区变化）之后没有重新计算，于是 0 px 仍然停在原来任务栏上方（差不多一个任务栏的高度，Win11 为 48 px × 缩放）。
    2. Dock 窗口底部有 5 个单位的透明阴影留白，可见的玻璃条（plate）因此比窗口底边高 5 个单位；0 px 时玻璃条离屏幕底边还有 5 个单位。
  - 修复：新增 DockPlacement，按显示器实际边界和任务栏的真实状态计算。
    - 任务栏在底部且可见：Dock 紧贴任务栏上方。
    - 任务栏被 ClearDesk 完全隐藏、被 Windows 自动隐藏、在左 / 右 / 上边，或没有任务栏：0 px = 可见玻璃条的底边正好贴着屏幕最底边一行像素（不再使用工作区底边，所以即使工作区还没更新也是对的）。透明阴影留白可以伸到屏幕外面。
    - 位置按显示器的物理像素换算（100% / 125% / 150% 缩放一致），Dock 窗口所在的显示器为准，不再固定取主显示器工作区。
    - 实时响应：每 400 ms 检查显示器、工作区、任务栏状态、缩放的变化，变了就重新排版并就位；完全隐藏任务栏生效、退出、切换位置、改缩放、改「距屏幕底部距离」都立即跟随。
  - 自动隐藏（窗口遮挡时下滑）：滑出位置改为显示器底边之外，不再用主屏高度；召回区域仍是显示器最后两行像素（物理底边，任务栏有无都一样）。
- 版本号统一为 2.3.2。外壳右键菜单包未改动（2.2.9.0），无需重新「一键启用」。

说明：「距屏幕底部距离」的其他数值（例如默认 12 px）仍然是玻璃条底边到上述基准线的距离。
