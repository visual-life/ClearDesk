# ClearDesk 1.9.2 — 内存优化与新图标

维护者：visual-life。本地交付，尚未发布到 GitHub。包含 1.9.1 全部修复。

## 内存

| 场景（本机，2026-10-22） | 工作集 | 私有内存 |
|---|---|---|
| 1.9.1，开机启动模式，60 秒后 | 376 MB | 314 MB |
| 1.9.2，同上（默认软件渲染） | 约 30 MB | 138 MB |
| 1.9.2，开启 GPU 硬件加速 | 约 37 MB | 291 MB |

组件：音乐（QQ 音乐）、时钟、天气、Dock、透明任务栏。空闲 CPU 两版均约 0.1%。工作集在修剪后会随使用缓慢回升，以私有内存为准。

改动：

- **默认软件渲染**：WPF 的 GPU 渲染在核显上为 D3D 设备与驱动分配约 150–170 MB 私有内存。ClearDesk 组件尺寸小、多为静态，软件渲染下空闲 CPU 无明显变化。设置 → 通用 → “GPU 硬件加速渲染”可重新开启（重启 ClearDesk 生效），或设置环境变量 `CLEARDESK_GPU=1`。
- **壁纸按屏幕尺寸解码**：磨砂材质读取的壁纸原先按原图分辨率常驻，现在不超过显示器长边。
- **GPU 占用采样**：性能组件原先每 6 秒用 ReadCategory 复制整个“GPU Engine”计数器类别（所有引擎实例 × 全部计数器），改为单个 PDH 通配查询，组件关闭时释放。
- **回收**：关闭设置窗口 2 秒后、启动 12 秒后及每 3 分钟空闲时，压缩回收托管堆（含大对象堆）并修剪工作集；配置中关闭并发 GC，少一个后台 GC 线程与其预留内存。

## 新图标

玻璃窗口叠层＋星光图标（非音乐主题），用于 exe 图标、任务栏、托盘、设置窗口左上角与标题栏、各组件窗口、README（assets/ClearDesk.ico 16–256 px，assets/ClearDesk.png 512 px）。

## 验证

- 基础自检、回归（设置“通用”页开关数改为 9）、客户端歌词、LRCLIB 联网测试通过。
- 启动后设置窗口左上角显示新图标与“版本 1.9.2”。

## 限制

软件渲染下 Dock 放大等动画在高分屏、高刷新率上可能不如 GPU 渲染顺滑；如在意可打开“GPU 硬件加速渲染”，代价是约 150 MB 内存。
