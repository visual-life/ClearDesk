# ClearDesk 1.8.0 — 自动天气与桌面操作增强

维护者：visual-life。包含 1.7.0 的设置界面与已有 Dock 材质、音乐功能。该阶段更新已包含在 1.8.2 和 1.9.1 发布版中。

## 六项更新

| 功能 | 用法与行为 |
| --- | --- |
| 自动天气 | 设置 → 外观与材质，开启“天气”和“自动天气联网”，应用设置。自动获取近似城市，显示温度、天气、湿度、风速和天气时间；不再提供手选城市 |
| Dock 关闭应用 | 右键运行中的应用 → 关闭应用。正常关闭全部窗口；应用可弹出未保存提示或取消关闭。固定图标保留，临时图标随窗口关闭移除 |
| 收纳新建 | 右键收纳空白处 → 新建 → 文件夹／文本文档／Markdown 文档，可修改名称和扩展名；同名自动编号 |
| 启动台发送 | 右键项目 → 发送至桌面收纳 → 选择收纳格或新建。仅添加引用，重复发送不重复添加；目标已关闭／收起时自动打开 |
| 组件拖动 | 拖动标题、普通文字或空白区域；位置锁定仍然有效。按钮、输入框、滑块与图标操作保留各自行为；Dock 和启动台保留已有专用交互 |
| 性能优化 | 缓存应用名称与窗口标识；隐藏／收起组件不做定时刷新；天气共用连接与缓存，关闭时取消请求 |

## 文件保存位置

桌面收纳中新建的文件保存到 Windows 当前桌面目录（支持桌面重定向）。其他收纳格中新建的文件保存到 `%LOCALAPPDATA%\ClearDesk\Files\收纳格标识`，右键“打开新建文件所在文件夹”可查看。已有文件不会被覆盖，移除引用不会删除原文件。预览／测试模式使用程序目录里的独立 `preview-data`，不向真实桌面创建测试文件。

## 天气联网说明

- [IPwho.is](https://ipwhois.io/documentation) 看到连接的公网 IP，并返回近似城市；代理／VPN 可能使城市与实际位置不同。不是 GPS 定位，无手选回退。
- [Open-Meteo](https://open-meteo.com/en/docs) 接收城市坐标，返回当前天气模型数据（[CC BY 4.0](https://creativecommons.org/licenses/by/4.0/)）；城市坐标仅保留两位小数用于请求，不落盘。
- IP、坐标、定位响应不写入配置或日志。天气仅在内存缓存 20 分钟；主动右键刷新会重新定位。初次失败显示不可用，之后刷新失败保留上次结果并标注更新失败，5 分钟后重试。
- .NET 运行配置已修复 HTTPS 协商问题，证书验证仍正常启用。联网服务不可用时，不生成假天气或偷偷改成固定城市。

## 验证

本次执行独立配置的完整桌面回归、基础自检，并通过应用本身完成真实 IP 定位和天气显示测试。真实联网测试不记录城市和坐标。天气画面检查使用固定示例数据，不能作为实况截图；新增菜单检查使用实际 WPF 模板。

本机 **151 项桌面回归、17 项基础自检通过**；自动定位与天气显示真实联网测试通过。两个独立测试窗口首次扫描读取窗口属性 2 次，之后连续 12 次扫描新增读取为 0；首次扫描 1.07 ms，后续平均 0.33 ms。这是有限场景的重复查询测量，不是完整应用的性能对比。

完整结果见发行包内验证记录。性能优化集中于减少重复工作，没有宣称整机 CPU／内存的固定下降比例。普通第三方程序对“关闭”的最终行为由自身决定，例如可能关闭到托盘；权限高于 ClearDesk 的窗口可能拒绝请求。

## 使用新版

退出旧版，将 `ClearDesk-1.8.0-含源码.zip` 完整解压后运行 `ClearDesk.exe`。保留 `taskbar` 目录，旧设置继续使用；旧城市字段会被忽略并在下次保存时移除。首次使用天气需开启上述两个开关。未替换用户正在运行的程序、桌面快捷方式或开机启动路径。

发行包包含对应源码、测试记录、`source-commit.txt` 和逐文件 SHA-256；不包含用户配置或桌面文件。
