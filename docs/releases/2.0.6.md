# ClearDesk 2.0.6

发布日期：2026-10-23。维护者：visual-life。

## 变更

- Dock 新增“距屏幕底部距离”（设置 → Dock 与启动台，0–300 px）：拖动滑块 Dock 实时上下移动并自动保存；窗口遮挡时自动隐藏、底边唤出都按新位置计算。
- 快捷控制：点击 WLAN 磁贴的文字区域改为直接打开 Windows 11 快速设置里的 WLAN 网络列表（可直接连接/断开连接、“更多 Wi-Fi 设置”），不再跳到设置 → 网络和 Internet → WLAN 页面；“可用网络”快捷入口同样打开这个列表。系统不支持时自动改为打开 WLAN 设置。
- 调整组件大小时也会显示对齐参考线：拖动组件右下角缩放、拖动收纳格和便签的边缘/右下角时，右边和下边会吸附到其他组件的边缘和中线、屏幕/工作区边缘，宽或高与其他组件相同时也会吸附（虚线标出两个等长的边）；按住 Alt 临时关闭吸附。
- 便签支持插入图片：
  - Ctrl+V 粘贴截图或复制的图片文件、把图片文件直接拖进便签，或右键 → “插入图片…”。
  - 图片复制保存到本机配置目录（note-images），原文件不受影响；删除图片或删除便签时一并清理。
  - 图片圆角、细描边，与便签风格一致；悬停时右上角“×”删除、右下角拖动调整大小；右键图片可选原宽/中等/小图、复制图片、用默认程序打开、删除图片。
  - 便签不再显示滚动条，直接用鼠标滚轮上下滚动；输入时自动跟随光标。
- 新增“动态壁纸实时模糊”开关（设置 → Dock 材质 / 组件材质处，默认关闭）：开启后“磨砂”材质的组件改为由系统合成器（DWM）实时模糊身后的真实画面，支持 Wallpaper Engine 等动态壁纸；由显卡完成，会略增加 GPU 占用，CPU 基本不变。关闭时仍只模糊静态壁纸图片。
- 顶部任务栏自动隐藏减少误触：只有鼠标碰到屏幕顶边上“有图标的位置”（开始/应用图标一组、右侧托盘与时钟一组）才会唤出任务栏，空白位置不再唤醒。图标位置通过 UI 自动化读取并每 5 秒刷新一次；读取失败时恢复为整条顶边都可唤出。按 Win 键、打开开始菜单等行为不变。
- 版本号统一为 2.0.6。

## 说明

- WLAN 网络列表通过资源管理器打开（ms-availablenetworks:），在本机 Windows 11 26H2 上已确认弹出的是快速设置里的 WLAN 列表。
- 动态壁纸实时模糊与 Dock / 启动台的磨砂使用同一种系统背景模糊；在“节电模式”或关闭了透明效果时，系统可能显示为纯色。
- 便签图片排在文字下方，暂不支持在文字中间插入。
- 完整功能见 [2.0.5](2.0.5.md) 更新说明。
