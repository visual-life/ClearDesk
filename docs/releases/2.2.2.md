# ClearDesk 2.2.2 发布说明

发布日期：2026-10-27

本版回应 7 条反馈：桌面收纳激活时闪一下、Dock 偶尔跳动、部分组件重启后位置变化、图片相册只能新建一个、时钟组件可去掉边框、所有组件可自定义背景图、组件放大时边长（边距）没有按比例缩放。

## 1. 点别的窗口再点「桌面收纳」会闪一下

- 现象的前提：设置里开启了「动态壁纸实时模糊」（你的设置里是开的）。实时模糊不是画在组件里的，而是组件正下方的一个独立窗口（DWM 主机背景）。
- 原因：组件被激活 / 被固定到桌面最底层（2.0.8 的「锁定后固定在最底层」）时，z 序改变，但模糊窗口只在组件移动 / 改大小时才跟着调整，其余靠每 1.5 秒一次的定时器——这段时间里模糊层停在组件上面，看到的就是一块没有图标和文字的模糊块，然后「闪」回正常。
- 修复：给组件窗口挂 `WM_WINDOWPOSCHANGED`，z 序或位置一变立刻把模糊窗口放回组件正下方。
- 测试：对真实的 DWM 模糊窗口反复切换 HWND_BOTTOM / HWND_TOP / NOTOPMOST，每次都必须紧贴在组件下方（4/4）；另有「复现」测试，关闭修复后同样的操作 3 次里 3 次错位。

## 2. Dock 栏有时不稳定、会跳动

- 原因（代码分析 + 计数测试，没有在你的机器上抓到现场）：Dock 订阅「运行中的应用」变化，任何程序开 / 关任何窗口都会触发整个 Dock 重建，重建会让悬停放大归零、底板重新排版；另外自动隐藏在窗口激活 / 最小化的瞬间会得到忽大忽小的矩形，Dock 就滑出又滑回。
- 修复：重建请求合并 250 毫秒，并比较「应用列表 + 顺序 + 运行状态」的签名，相同就跳过（`RebuildCount` / `SkippedRebuilds` 计数）；自动隐藏后重新出现需遮挡消失 280 毫秒；隐藏、指针唤出仍然立即。
- 测试：签名规则、延迟显示规则、对真实 Dock 连发 5 次「应用变化」不重建。

## 3. 有些组件重启后位置变了

排查了保存和恢复路径，找到三处，已逐一修复并加测试：

1. **新建组件的位置不立即保存**：`NewWidget` 在创建窗口之前保存，创建后的位置（尤其是 2.2.1 的「出现在鼠标右键位置」）要等到下一次无关的保存才写盘；直接重启就回到默认位置。现在创建后立即保存。
2. **系统移动窗口被当成用户移动**：显示器 / 缩放 / 工作区变化（登录、睡眠恢复、接拔显示器、顶部任务栏收放）时 Windows 或 WPF 会挪动窗口，旧代码把每一次 `LocationChanged` 都写进 settings.json。现在新增 `PositionGuard`：组件刚加载后的 4 秒、以及收到 `WM_DPICHANGED` / `WM_DISPLAYCHANGE` / `WM_SETTINGCHANGE` / `DisplaySettingsChanged` 后的 2.5 秒内，没有拖动、没有按住鼠标的位置变化不保存，稳定后若与已保存位置不同且已保存位置可见，就放回去。
3. **启动时的「是否在屏幕内」检查**：旧代码拿 DIP 坐标去和像素的 `WorkingArea` 比较，还受顶部任务栏保留区影响，不合格就改到 (20,20)。现在按 DIP 和整块屏幕判断，真的不可见时只在视觉上救回，不覆盖已保存的位置（用户下次拖动才更新）。

说明：你这台是单显示器、100% 缩放，我没能在这台机器上复现「系统挪动窗口」的现场，2 的机理来自代码分析和模拟（测试里用 `NoteSystemChange` + 手动改 Left/Top 模拟）；1 是确定可复现的（测试里：新建 → 不做别的 → 读磁盘上的 settings.json）。
测试：14 种组件「放置 → 保存 → 像 settings.json 一样序列化 → 关闭 → 读回 → 重新创建」位置不变；右键新建后磁盘上立即有位置；不可见的保存位置不被覆盖；系统挪动不保存且会放回；正常拖动仍然保存。

## 4. 图片相册（及其他）可以放多个

- 实例编号：第一个仍叫 `album`（所有 2.2.x 的文件、文件夹、设置原样可用），后面是 `album~2`、`album~3`…；每个实例有独立的设置项（`settings.json` 的 `Widgets`）、数据文件（`widgets\album~2.json`）、图片文件夹（`widgets\album-images~2`）、背景图。
- 适用：图片相册、待办清单、倒计时 / 番茄钟、日程、快捷启动。仍是单个：剪贴板历史（只有一个系统剪贴板）、网速流量、日出日落 + 空气质量，以及时钟、天气、音乐、日历、黄历、性能、快捷控制。
- 用法：桌面右键 / 组件右键 → 新建组件 → 图片相册，已有一个在桌面上时会新建「图片相册 2」，窗口标题带编号，默认位置错开一点；设置 → 组件管理逐个列出（名称带编号），可显示 / 关闭 / 重置大小 / 定位 / 删除。关闭只是隐藏（再显示是原来那个，不会新建）；删除第 2 个及以后的实例会清掉它的数据和图片副本，第一个保持 2.2.x 的行为（保留数据文件）。编号被释放后会复用（得到一个空的）。
- 迁移：不需要迁移——已有的单个组件就是第一个实例，数据文件和图片文件夹没有移动。
- 测试：2.2.1 布局的相册升级后设置和图片完整；创建 3 个相册，图片、间隔、铺放、背景、位置、锁定、大小各自独立；序列化后重启全部恢复；组件管理列表 / 隐藏 / 再显示 / 删除只影响自己；待办条目、番茄钟设置各自独立；剪贴板、网速、日出日落仍是单个。

## 5. 无边框 / 透明背景

- 右键 →「无边框 / 透明背景」：不画玻璃面板、边框、材质、模糊，只显示内容；「文字阴影（无边框时）」默认开，保证在任何壁纸上可读。
- 仍可拖动（空白处也接收鼠标，只是不画出来）、调整大小（悬停时才出现右下角手柄）、锁定、折叠；设置按组件保存，重启保留；每个实例单独设置。
- 可用：时钟、日历、黄历、天气、音乐、性能、快捷控制、待办、倒计时 / 番茄钟、日程、剪贴板、网速、快捷启动、图片相册、日出日落、桌面收纳。不提供：便签（本身就是彩色纸）、Dock、启动台。
- 和自定义背景可同时用：无边框 + 背景图 = 只有一张圆角图片加内容。
- 测试：开关后外圈 6 像素内完全没有像素（对比玻璃时 5935 个）；空白处命中测试仍有目标；阴影可关；锁定可用；保存、重启恢复、关闭后边框回来。

## 6. 所有组件的自定义背景

- 右键 →「自定义背景」：选择图片…、从剪贴板粘贴（复制的图片或图片文件）、把图片拖到组件上（相册、收纳格、便签、快捷启动自带拖放行为，仍用菜单）；填充方式：填充（裁剪铺满）/ 适应（完整显示）/ 拉伸；图片不透明度 100–20%；压暗 0–60%（默认 25%，让文字看清）；移除背景。
- 图片复制进 `%LOCALAPPDATA%\ClearDesk\widgets\backgrounds`（每个组件实例一份，原文件删除后仍可用；最大 40 MB；非图片或损坏的文件会被拒绝并保留现有背景；超大图按 2400 像素宽解码）；换图 / 移除时删除旧副本。
- 随组件缩放：背景是铺在组件内容下面的一层，跟随组件宽高实时变化（填充模式居中裁剪）；圆角裁剪；和玻璃 / 雾面材质、实时模糊、无边框、锁定、多实例同时使用。
- 测试：中文文件名、复制进数据文件夹、放大 1.8 倍后图层与组件同尺寸、三种填充、不透明度 / 压暗、各组件互不影响、原文件删除 + 重启 + 锁定 + 自定义大小后恢复、换图删旧副本、移除只删自己的、拖放文件（跳过不存在的）、拖放图片数据、粘贴、非图片 / 损坏文件拒绝、便签和收纳格也能用。

## 7. 组件放大时边长（边距）自适应

- 理解：组件放大时内容会按比例放大，但边距、间距、字号层级看上去没有跟着变——我把「边长」理解为边距 / 间距 / 圆角这类边框度量。（如果你指的是别的现象，请告诉我。）
- 原因：① 内容缩放上限 2.5 倍，而尺寸上限是 4 倍，放到 2.5 倍以上内容和边框都不再放大，只剩更多空白；② 瘦高或扁宽的组件，缩放按宽高中较小的比例，另一方向多出的空间全部变成空白，外边距不变；③ 番茄钟页签、阶段文字、按钮字号相对 46 号时钟偏小。
- 修改：内容缩放上限提高到 4 倍（与尺寸上限一致；边框、圆角、手柄本来就随内容一起缩放）；多出的空间按比例增加外边距（`EdgeFactor`，1×～2×，默认形状仍是 20）；番茄钟的间距按多出的高度拉开（最多 3 倍）并居中；页签 12→15、阶段文字 13→16、按钮 12→14、今日完成 12→14、方案摘要 12→13。
- 测试：缩放 / 边距 / 间距的数学与夹取；日历瘦高时边距 20→40，同比例放大回到 20，重置回到 20；放大 4 倍内容缩放 = 4。渲染对比图在发行包的 `source/docs/images/2.2.2/`（`pomodoro-compare-221-vs-222.png` 为 2.2.1（上）与 2.2.2（下）同尺寸对比，2.2.1 原图在 `before221/`；单张：番茄钟 1×1、1×2、2×2、2.5×1、3.5×3.5，时钟玻璃 / 无边框 / 无边框 + 背景 / 玻璃 + 背景 / 瘦高）。
