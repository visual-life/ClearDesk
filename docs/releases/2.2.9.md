# ClearDesk 2.2.9

- 文件夹映射新增紧凑模式，默认开启。
  - 最小可以拖到 120×96 px（2.2.8 是 228×168）；四周几乎没有内边距，圆角变小，内容贴近边缘。
  - 标题移到底部一条窄栏：左边是文件夹名，右边是三个小按钮：列表 / 图标视图、在资源管理器中打开、更多（打开右键菜单）。
  - 图标、文字和底栏随宽度一起变大；窄宽度下标题用省略号，按钮不重叠、不被裁切。
  - 右键「紧凑模式（标题在底部）」可以切回 2.2.8 的布局。
  - 2.2.8 修好的防抖动、隐藏滚动条和自适应缩放都保留。
- 启动台可以编辑。
  - 右键程序：「从启动台移除」只隐藏条目，绝不删除真实文件；固定的项目可以「向前移动 / 向后移动」排序。
  - 右键空白处：「恢复已移除的项目」，可以逐个恢复或全部恢复。
  - 新增「固定到启动台」：桌面和资源管理器里文件 / 文件夹的右键菜单（Win11 一级菜单 ClearDeskShell，以及「显示更多选项」里的经典菜单）、桌面收纳格和 Dock 的右键菜单，与「固定到 Dock」「发送至桌面收纳」放在一起。
  - 固定的项目和顺序都会保存。
- 桌面收纳格、Dock 和启动台的程序右键新增「以管理员身份运行」（ShellExecute runas）。
  - 在 UAC 里点「否」（错误 1223）时静默处理。
  - 商店 / UWP 应用、文件夹、文档、网址和系统图标不显示这一项。
- Win11 一级菜单包 ClearDeskShell 升级到 2.2.9.0（新增文件 / 文件夹上的「固定到启动台」），升级后需要在 设置 里重新点一次「一键启用」。
- 版本号统一为 2.2.9。
