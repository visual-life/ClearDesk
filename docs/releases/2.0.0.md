# ClearDesk 2.0.0 — 新建组件、便签、磁吸对齐

维护者：visual-life。本地交付，尚未发布到 GitHub。基于 1.9.2（含内存优化与新图标）。

## 锁定状态一目了然

组件右键菜单中的状态项：锁形图标 + 要执行的操作 + 当前状态。

- 未锁定：开锁图标，“锁定位置”，“当前：位置未锁定”
- 已锁定：琥珀色锁图标，“解锁位置”，“当前：位置已锁定”

切换时组件底部弹出约 1.5 秒的提示；已锁定的组件在鼠标悬停时右上角淡入一个小锁。

## 新建组件

- **桌面右键**：“ClearDesk 新建组件” → 便签／桌面收纳格／时钟／天气／音乐／日历／黄历 / 农历／性能。注册在 `HKCU\Software\Classes\DesktopBackground\Shell\ClearDesk`（不需要管理员）。ClearDesk 每次启动时按当前 exe 路径重写，设置 → 外观与材质 →“桌面右键新建组件”可关闭（关闭即删除注册）。`ClearDesk.exe --uninstall` 会删除此菜单和开机启动项。
- **组件右键菜单**和**托盘菜单**也有“新建组件”。
- 菜单命令为 `ClearDesk.exe --new-widget <类型>`。ClearDesk 已在运行时，通过命名管道（仅限当前用户）把请求转给正在运行的实例；未运行时会直接启动并创建该组件。
- 时钟、天气这类只能有一个的组件如果已经开着，会直接显示并提示“已在桌面上”；便签和收纳格每次新建一个。

### Windows 11 一级菜单

Windows 11 的新式右键菜单只显示通过 IExplorerCommand 实现、并带有包标识（MSIX 或 sparse package）的扩展，安装包必须签名且证书受系统信任（自签证书需要管理员导入受信任根）。ClearDesk 是绿色版 .NET Framework 程序，没有原生 COM 外壳扩展，也没有签名证书。因此本版采用经典注册表菜单：Windows 11 上在“显示更多选项”（或 Shift+F10、Shift+右键）里，Windows 10 直接显示在一级菜单。要放进一级菜单，需要另做一个原生 IExplorerCommand DLL、带签名的 sparse package，以及安装和卸载流程。

## 便签

- 多行文字，停止输入 0.6 秒后自动保存，关闭窗口或退出时也会保存；保存在 settings.json 的 `Notes` 中，重启后恢复。
- 可以建多张，每张单独记录位置、大小、颜色和材质。
- 颜色：暖黄、薄荷、天蓝、樱粉、丁香、无色；材质沿用组件的玻璃／雾面。
- 右下角拖动调整大小（最小 200×140）；双击标题收起。
- 删除：悬停时标题右侧显示 ×，或右键“删除便签”。有内容时会先确认，空便签直接删除。

## 磁吸对齐

- 吸附目标：工作区和屏幕的边缘与中线、其他组件的边缘（含左右／上下相贴）与中线，以及其他组件之间已有的间距（等距排列）。
- 阈值 8 DIP，按显示缩放换算为像素；横向和纵向分别取最近的吸附位置。
- 吸附时在全屏透明、不接收点击的覆盖层上画细蓝线，等距间隔用虚线标出两段相同的间距；松开鼠标后覆盖层关闭，不常驻内存。
- 按住 Alt 时自由放置；设置 →“磁吸对齐”可整体关闭（默认开）。

## 验证（本机，2026-10-22）

- 自检新增 20 项：吸附几何、参数解析与非法类型拒绝、注册表注册／覆盖／删除（在测试键下）、便签序列化、旧版设置兼容、锁定文字。
- 回归测试新增 17 项：锁定菜单文字与提示、提示自动消失、新建组件菜单项、便签新建／自动保存／多实例／删除／重开恢复、单例组件不重复、拖动吸附与参考线、Alt 和关闭磁吸时自由放置。
- 基础自检、回归、客户端歌词、LRCLIB 联网测试全部通过。
- 实机：启动后桌面菜单注册成功；第二次执行 `--new-widget note` 时，正在运行的实例新建了便签，第二个进程立即退出；用鼠标拖动便签时显示参考线并对齐到音乐组件顶边；右键菜单显示锁定状态。

## 内存

开机启动模式下，60 秒时测量（组件为音乐、时钟、天气、Dock、透明任务栏，同一时段连续测两版）：1.9.2 私有内存 147.6 MB，2.0.0 为 152.7 MB（多约 5 MB，来自命名管道线程和新增代码），没有明显回升。磁吸参考线只在拖动时存在。

## 限制

- Windows 11 的桌面菜单项在“显示更多选项”里（原因见上）。
- 中文输入法处于中文模式时，程序模拟按键可能被输入法拦截，这不影响正常键盘输入。
- 磁吸按主显示器的 DPI 换算；多显示器且缩放比例不同时，跨屏吸附可能有 1–2 px 偏差。
