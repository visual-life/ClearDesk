# ClearDesk 2.3.1

- 「完全隐藏任务栏」现在在任务栏位于上、下、左、右任意一边时都生效（2.3.0 只有顶部）。
  - 仍然只有按 Windows 键 / Ctrl+Esc 打开开始菜单或搜索时才显示；退出和崩溃时恢复任务栏和工作区（含左 / 右 / 下边）。
  - 最大化的窗口会跟着工作区一起占满被收起的任务栏位置。
  - 任务栏如果被 Windows 自己设成「自动隐藏」（下 / 左 / 右），ClearDesk 不去管它，避免两边抢着移动同一个窗口。顶部的「自动隐藏」行为不变。
- 启动台 / 收纳格的打开、关闭、折叠更流畅。
  - 收纳格折叠 / 展开：不再逐帧改窗口大小和重排图标（2.3.0 每帧 6–20 ms 的布局：折叠、展开各 6 次测试里各有 81 次超过 6 ms 的渲染回调；现在分别是 6 次和 1 次），只动一个裁剪框的高度。
  - 启动台：整个窗口用透明度渐变（缓存位图），首屏 35 个图标先显示，其余在动画结束后补上；不再逐帧位移。
  - 实测数据见下方「帧时间」。
- 修复「新旧版本同时运行，桌面图标消失，双击隐藏桌面才出现，关掉又消失」。
  - 根因：崩溃保护（--guard）在启动时记下「桌面图标当前是显示还是隐藏」，退出 / 崩溃时恢复成它记下的状态。如果另一个 ClearDesk（旧版或第二份）此刻已经把图标藏起来了，「隐藏」就被当成要恢复的状态：之后每次关闭都把图标藏回去，只有双击切换才会再显示。恢复文件 recovery-v11.json 在各版本、各实例之间共用，一个实例退出还会把另一个的删掉。
  - 修复 a：启动时和运行中检测另一个 ClearDesk（同一 Windows 会话、不含测试和保护进程）；弹窗询问是否关闭旧的（是：关闭并等它的保护进程结束后恢复图标；否：当前这个不启动 / 保持现状）。开机自启时静默退出。无法关闭（例如旧的以管理员身份运行）会提示到任务管理器里结束。
  - 修复 b：启动和退出时一律把桌面图标恢复为显示，除非你在 Windows 里自己关闭了「显示桌面图标」；崩溃保护、另一个实例留下的隐藏状态同样会被恢复。
  - 修复 c：不再读取「当前状态」当作要恢复的状态，隐藏状态不会被反过来保存；恢复文件改为每个进程一份（recovery-v12-<pid>.json）。
  - 2.2.x 的行为：同样的互斥名（所有版本相同，所以正常情况下两个不会同时运行）、同样记下当前状态的保护进程，没有跨版本检测。如果旧版还在运行：到任务管理器里结束所有 ClearDesk.exe，再启动新版；或者先启动新版并在弹窗里选「是」。
- 所有组件都能缩到文件夹映射那么小（120 × 96 px）。
  - 收纳格最小 120 × 96，宽度小于 240 px 时标题栏变薄、图标格变小、字更紧凑，隐藏搜索按钮；快捷启动的图标在窄宽度下重新排列；其他组件按比例缩小内容，不裁切、不重叠（逐个渲染检查）。
  - 时钟的「Wednesday」不再折成两行压在时间上。
- 搜索可以隐藏：设置 → 桌面收纳 →「隐藏搜索」，收纳格和启动台的右键菜单里有「显示搜索」，保存在 settings.json（HideSearch）。
- 版本号统一为 2.3.1。外壳右键菜单包未改动，保持 2.2.9.0，无需重新「一键启用」。

## 帧时间（测试脚本：每个场景 6 次，软件渲染，Rendering 事件间隔）

| 场景 | 2.3.0 p95 | 2.3.1 p95 | 2.3.0 >20 ms 次数 | 2.3.1 >20 ms 次数 |
| --- | --- | --- | --- | --- |
| 启动台打开 | 32.1 | 25.5–28.1 | 9.8 | 6.2–6.7 |
| 启动台关闭 | 39.8 | 25.2–27.0 | 6.2 | 4.3–4.5 |
| 收纳格折叠 | 28.1 | 21.9–24.6 | 6.7 | 2.8–4.5 |
| 收纳格展开 | 25.0 | 23.0–24.1 | 5.0 | 3.5–4.8 |

这是合成测量（不在你的显示器上），数值有波动；打开启动台时第一帧前仍有 40–120 ms 的窗口创建时间（动画开始前，窗口透明）。
