# ClearDesk 2.0.8 发布说明

发布日期：2026-10-23

## 1. 网易云音乐最小化后组件停住（重要修复）

**现象**：网易云音乐最小化（或被其他窗口完全挡住、关到托盘）后，音乐组件的进度和歌词停住，显示“已暂停”，恢复窗口才跳到正确位置。

**根本原因**：网易云 3.x 基于 Chromium（CEF），窗口最小化或完全被遮挡时会冻结界面，进度文字和播放按钮都不再更新；网易云也不提供系统媒体会话（SMTC）。ClearDesk 从 2.0.x 起用“最后一次实时进度 + 网易云自身的音频输出音量”推算进度。但 2.0.4 新增的快捷控制也使用 Windows 音频设备接口，两个模块对同一个系统音频组件各自声明了一个 COM 类，程序运行时第二个模块创建对象时类型冲突（InvalidCastException），读取网易云音量永远失败，推算时钟因而从不前进。命令行诊断模式不加载快捷控制，所以诊断结果一直正常，问题被掩盖。

**修复**：
- 两个模块都改为按 CLSID 创建音频设备枚举器，不再依赖各自的 COM 类声明；回归测试会先制造同样的冲突再验证读取音量。
- 网易云关到托盘时主窗口被隐藏，现在会枚举它的隐藏顶层窗口，继续从标题读取“歌名 - 歌手”，并按音频推算进度。
- 启动时网易云已最小化、读不到进度：从网易云播放队列取得时长，按音频推进；窗口恢复后用真实进度校准。
- 已暂停的网易云最小化后不再短暂误判为播放。
- QQ 音乐走系统媒体会话，不受影响（已实测）。

**可选诊断**：在 `%LOCALAPPDATA%\ClearDesk\` 下新建空文件 `music-trace.on`，即把每次读取（窗口状态、原始进度、音量、推算进度）记录到 `music-trace.txt`（超过 2 MB 自动清空）；删除该文件即关闭。

## 2. 歌词字体自适应放大

拉高音乐组件时，歌词卡片变高，当前句和后续歌词的字体按多出的高度放大（每多 160 像素约放大 100%），同时受组件宽度限制（宽度不足时不过度放大，避免一句歌词拆成很多行），最大约 2.4 倍；放大后剩余的高度再用来显示更多后续歌词。纯文本歌词同样放大。默认大小时与 2.0.7 完全一致。

## 3. 锁定的组件固定在最底层

- 锁定的组件（时钟、天气、音乐、日历、收纳格、便签等）始终处于桌面最底层，像桌面图标一样在所有普通窗口之下；点击它们不会再浮到其他软件或其他组件上方造成重叠。
- 点击锁定的组件不会抢走当前窗口的焦点；便签和收纳格例外（需要输入文字 / 搜索），但同样保持在底层。
- 未锁定的组件在编辑（拖动、调整大小）时仍可前置。
- Dock、启动台、置顶组件不受影响；组件管理的「定位」仍会短暂把组件提到最上并闪烁，结束后回到底层。
- Win+D 显示桌面的行为与之前一致。
