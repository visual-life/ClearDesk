# ClearDesk 2.2.1 发布说明

发布日期：2026-10-26

本版回应 5 条反馈：番茄钟时长可自定义、图片组件（图片相册）无法使用、快捷控制内置音量合成器、桌面收纳里加入此电脑 / 回收站等系统图标、新建组件直接出现在鼠标右键的位置。

## 1. 番茄钟时长可自定义

- 倒计时 / 番茄钟 → 番茄钟页，点「25 / 5 / 15 分钟 · 每 4 轮长休息 ⚙」（或右键菜单 →「番茄钟设置…」）打开设置面板：专注、短休息、长休息的分钟数，以及几轮专注后长休息，每项都有 − / + 按钮，可直接输入数字，也可用鼠标滚轮调整。
- 范围：专注 1–180 分钟，短休息 1–60，长休息 1–120，几轮后长休息 2–12。输入空白、小数、负数、文字或超出范围时不会保存，面板里显示原因。
- 预设：经典 25/5/15（4 轮）、50/10/20（4 轮）、45/15/30（3 轮）、90/20/30（2 轮），一键应用。
- 修改后立即保存（`%LOCALAPPDATA%\ClearDesk\widgets\countdown.json`），重启后保留；手动改坏的数值会被修正到合法范围。正在计时的这一轮不受影响，新的时长从下一轮开始；未在计时时立即生效。

## 2. 图片组件（图片相册）无法使用

先说明理解：反馈里的「图片组件」按「现在的图片组件完全不可以用」处理为 2.2.0 新增的**图片相册**（它是桌面上唯一专门放图片的组件；便签里的插入图片功能没有改动）。

### 原因

- 在真实电脑上用真实的图片解码器测试过：含中文、`#`、`%` 的文件名和 3000 像素的大图都能正常显示，所以问题不在图片解码。
- 2.2.0 的图片相册**只有右上角一个很小的「＋」按钮，只能选整个文件夹**；没有选择单张图片的入口，不支持把图片拖进来，不支持粘贴（Ctrl+V），空白状态也只有一句「还没有图片」，没有任何可点的按钮。对只想放一张图片的人来说就是「没法用」。
- 选择文件夹的对话框没有归属窗口：组件固定在桌面最底层，对话框有可能出现在其他窗口后面，看上去点了没反应（这一条在测试里无法稳定复现，按「可能原因」处理，已一并修复）。
- 图片只是记录原路径，原文件被移动或删除后组件就变空。

### 现在

- 空白状态显示「添加图片…」大按钮和说明；右上「＋」菜单、右键菜单都有「添加 / 更换图片…」「粘贴图片」「添加图片文件夹…」。
- 支持三种方式：文件对话框（可多选）、把图片文件 / 文件夹 / 网页里拖出的图片拖进组件、复制图片后 Ctrl+V 或右键 → 粘贴图片（也支持复制的图片文件）。
- 单张图片会**复制到 ClearDesk 的数据文件夹**（`%LOCALAPPDATA%\ClearDesk\widgets\album-images`，内容相同只存一份，最多 300 张、单张不超过 40 MB），原文件删除后仍然显示；文件夹则保持引用。重启后保留。
- 右键 → 铺满（裁剪）/ 完整显示，设置保存；右键 → 移除当前图片（复制进来的会删除副本，文件夹里的图片只是隐藏，**绝不会删除你的原文件**）、清空全部图片。
- 快捷启动里的文件对话框也改为有归属窗口，不会躲到后面。

## 3. 快捷控制内置音量合成器

- 点「声音」不再打开系统设置，而是在组件内滑入「音量合成器」页（淡入 + 平移），左上 ← 返回。
- 页面内容：主音量滑块与静音、当前输出设备（点击可切换）；下面是每个应用一行——图标、名称、音量滑块、静音按钮、百分比；包含「系统声音」；同一个程序的多个声音会话合并为一行一起调整；没有应用在发声时显示提示。
- 通过 Windows Core Audio（IAudioSessionManager2 / ISimpleAudioVolume）读取和设置，名称和图标取自进程。只在页面打开时每 1.5 秒刷新，返回或关闭组件立即停止并释放。
- 没有滚动条：应用多时用鼠标滚轮滚动；组件拉大时自适应。底部有小链接「打开系统音量合成器」。
- 真机验证：读取到系统声音和 8 个应用会话；只对 ClearDesk 自己的会话做了设置 / 静音 / 恢复往返测试（均成功并已恢复），没有改动其他软件的音量。可用 `ClearDesk.exe --mixer-diag [输出文件]` 查看。

## 4. 桌面收纳里的此电脑、回收站等

- 桌面收纳 / 收纳格右键 →「添加系统图标」：此电脑、回收站、控制面板、用户文件夹、网络，勾选即添加，再点取消。图标是 Windows 的真实图标，回收站按空 / 满显示不同图标并随状态变化。
- 点击通过资源管理器打开（`explorer.exe shell:::{...}`）；回收站右键有「打开」「清空回收站」（Windows 自己的确认窗口）。
- 「收集桌面」模式会收集桌面上已显示的系统图标（按 Windows「桌面图标设置」；未设置时只有回收站，这是 Windows 默认）；可以从格子里隐藏、再添加回来。

## 5. 新建组件直接出现在鼠标位置

- 桌面右键 → ClearDesk 新建组件（原生菜单和经典菜单都是）、组件右键菜单里的「新建…」、收纳格右键 →「新建收纳格」创建的组件，左上角出现在你右键点击的位置（30 秒内的右键有效）。
- 位置限制在鼠标所在显示器的工作区内，不会跑出屏幕或压到任务栏；多显示器、负坐标、缩放比例不同（按 DPI 换算）都已处理；遵守「磁吸对齐」，贴近其他组件或屏幕边缘时吸附（按住 Alt 关闭吸附，或在设置里关闭磁吸）。
- 从设置 / 组件管理 / 托盘创建时没有鼠标上下文，保持原来的默认位置；已经在桌面上的单实例组件不会被移动。
