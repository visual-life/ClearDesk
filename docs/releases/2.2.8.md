# ClearDesk 2.2.8

- 修复 2.2.7 文件夹映射的抽搐问题：把高度拖到刚好放不下全部项目附近时，组件会上下抖动、内容反复被裁切。
  - 原因：布局反馈循环。标题缩放取决于字号，字号又取决于列表剩余高度，而列表剩余高度又被标题高度挤占，结果在两个尺寸之间来回跳。
  - 现在只按用户设定的组件宽高和项目数计算尺寸，不再读取列表实际可见区域，也绝不修改组件自身的宽、高、最小高度，不使用 SizeToContent。
  - 标题缩放只由组件尺寸决定；列表和图标尺寸加入迟滞（变化 1 档且高度变化不到 3 px 时保持不变）。
  - 拖动时用低优先级合并重算，每帧最多算一次。
  - 滚动条始终隐藏（用滚轮滚动），也不占布局宽度；列表行宽改由用户设定的宽度计算，不再依赖可见区域宽度。
- 图标视图同样修复；其他自适应组件（歌词、天气、倒计时、快捷控制等）已检查，它们只按用户尺寸计算，不存在这个循环。
- 新增回归测试：在临界高度附近逐 1 px 缩小、放大，断言组件不会改自己的尺寸、图标单调变化、静置时不振荡，以及模拟抖动拖动。
- 版本号统一为 2.2.8。
