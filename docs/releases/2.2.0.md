# ClearDesk 2.2.0 发布说明

发布日期：2026-10-26

## 修复：Dock 里的 Sparkle、英雄联盟最小化后再点击弹不出来

### 原因

- Sparkle、英雄联盟客户端（LeagueClientUx.exe）是**以管理员权限运行**的程序，ClearDesk 是普通权限。Windows 的 UIPI（用户界面特权隔离）不允许普通权限进程对管理员权限的窗口调用 `ShowWindow` / `OpenIcon` 还原——调用直接返回 5（拒绝访问），窗口依旧最小化。旧版 Dock 正是用这两个调用还原窗口，所以第一次点击会启动应用，最小化后再点就再也弹不出来。
- 英雄联盟还有第二个问题：Dock 固定的是 Riot 启动器，而真正的窗口属于它启动的 LeagueClientUx.exe，两者不是同一个 exe，Dock 认为「应用没有窗口」。
- 另有一类应用关闭窗口后只留在托盘，窗口是隐藏的，Dock 同样看不到。

### 现在怎么做

- 还原窗口改为向窗口发送 `WM_SYSCOMMAND`（SC_RESTORE / SC_MINIMIZE）消息：这类消息可以越过 UIPI，管理员权限窗口同样会响应。最小化用 SC_MINIMIZE。依次尝试：显示被隐藏的窗口 → SC_RESTORE（最多等 0.5 秒确认）→ ShowWindow / OpenIcon 兜底 → 置前（不模拟任何按键）。
- 窗口匹配增加「启动器 → 客户端」识别：沿进程的父进程链查找被固定的 exe（排除 explorer、cmd、powershell、svchost、ClearDesk 本身这类中性父进程，避免把无关程序归到一起），所以 Riot 启动器的图标会对应 LeagueClientUx 的窗口。
- 没有可见窗口时，先找该应用隐藏的主窗口（托盘程序），能显示就显示；显示不了才重新启动一次（单实例程序收到第二次启动后会自己把窗口弹出来）。
- 还原失败或窗口已消失时，不再「点了没反应」：自动退回到启动应用；同一个窗口的并发点击会合并。

### 验证

- 在真实运行的 Sparkle（管理员权限）和 LeagueClientUx（管理员权限）上用 ClearDesk 的真实还原代码测试：最小化 → 还原 → 前台都成功；测试后窗口状态已恢复。可用 `ClearDesk.exe --dock-diag [输出文件]` 查看窗口、是否管理员权限和父进程链，`--dock-activate <exe 关键字>` 对单个应用做同样的还原测试。
- 自动测试：用模拟窗口覆盖「管理员窗口」「应用忽略 SC_RESTORE」「窗口消失」「托盘隐藏窗口」「管理员托盘窗口」等情形，另有一个真实 WPF 窗口的最小化/还原测试。

### 局限

- 最小化到托盘的**管理员权限**应用，普通权限的 ClearDesk 无法把它的隐藏窗口重新显示出来；此时 Dock 退回到再次启动该应用，由应用自己（通常是单实例逻辑）弹出窗口。这一条只有单元测试，没有在真实的托盘管理员应用上验证。想彻底避免，可以用管理员权限运行 ClearDesk（本版没有这样做）。

## 新增 8 个桌面组件

全部沿用现有组件的风格：自由拖动、锁定、拖右边缘 / 下边缘 / 右下角调整宽高（内容重新排版）、白色 Windows 11 右键菜单、组件管理、材质、对齐参考线、位置与大小保存；在 桌面右键 → ClearDesk 新建组件（包括原生外壳菜单）和 设置 → 外观与材质 → 桌面组件里都有入口。后台定时器只在组件可见且未折叠时运行，启动时不做任何联网或重活。数据保存在 `%LOCALAPPDATA%\ClearDesk\widgets\`（写入先写临时文件再替换；文件损坏时改名保留，组件从空白开始）。

1. **待办清单**：添加、勾选、删除、↑↓ 调整顺序、隐藏 / 清除已完成。到期时间写法：`18:30`、`明天 9:00`、`后天`、`10/28 14:00`、`2026-12-01 08:00`、`30m`、`2小时后`。到期弹出托盘通知和组件提示，同一项只提醒一次，取消勾选后重新生效。
2. **倒计时 / 番茄钟**：倒数日（考试、生日；可设「每年」，2 月 29 日在平年算 2 月 28 日），距离近的在前，已过的在后；番茄钟开始 / 暂停 / 重置 / 跳过，默认 25/5/15 分钟、每 4 个番茄一次长休息（可改，如 `50/10/20`），阶段结束弹通知并提示音，今日完成数保存。1 秒定时器只在番茄钟运行时存在。
3. **日程**：今天和明天，快速添加（`明天 14:00 项目评审`、`10/28 面试`、`18:00 跑步`，不写时间为全天），点一条即可编辑，可删除；可导入 `.ics` 日历文件（UTC 时间换算为本地，全天事件，折行和转义）。**不读取 Windows 日历**：Windows 没有免密钥的本地读取接口；.ics 的重复规则（RRULE）不展开。
4. **剪贴板历史**：记录文本和图片，点一条重新复制（只是放回剪贴板，需要你自己按 Ctrl+V），可固定、删除、清空（保留固定项）、暂停记录。**不记录**：带「排除」格式（ExcludeClipboardContentFromMonitorProcessing、CanIncludeInClipboardHistory = 0）的内容，以及密码管理器（KeePass、1Password、Bitwarden 等）复制的内容。数量限制：文本 40 条（每条不超过 20000 字）、图片 6 张（单张 4 MB、合计 16 MB）。默认只放在内存里，退出即清除；可在右键菜单打开「保存文本历史」，此时只保存文本，并用 Windows 当前用户的 DPAPI 加密；图片永远不写入磁盘。
5. **网速流量**：实时下载 / 上传速度、今日累计流量（跨天自动清零、重启保留）、60 秒迷你曲线。只统计物理网卡，VPN / TUN / Hyper-V / VMware 等虚拟网卡不重复计数；处理 32 位计数器回绕和网卡重置。右键可「清零今日流量」。
6. **快捷启动**：文件、文件夹、网址、应用的图标网格（系统图标），把文件拖进来即可添加，右上 ＋ 可添加文件 / 文件夹 / 网址，点击打开，右键移动、重命名、移除；去重，最多 60 项，列数随宽度变化。
7. **图片相册**：选择文件夹或图片，淡入淡出轮播，间隔 3 秒到 5 分钟，铺满 / 完整显示，顺序 / 随机（一轮内不重复），可含子文件夹，最多 2000 张。图片按组件大小用 DecodePixelWidth 解码（最大 1920 像素宽），大照片不会占满内存；组件隐藏时暂停。
8. **日出日落 + 空气质量**：日出、日落时间由坐标离线计算（NOAA 公式，误差约 1 分钟，支持极昼 / 极夜），不联网；位置沿用 2.1.1 的天气位置（手动区县 → 缓存 → Windows 定位 → IP）。空气质量（AQI）：中国境内先问腾讯天气（区县，再市级），再用 Open-Meteo（美标 AQI），均无需密钥；结果缓存到 `widgets\sunair.json`，联网失败时显示缓存并注明更新时间；失败后退避重试，网络变化时立即刷新。注意两种来源的 AQI 标准不同（国标 / 美标），组件会标出来源和标准。

## 其他

- 设置 → 外观与材质 → 桌面组件 增加 8 个开关；组件管理列出这 8 个组件。

- 版本号统一为 2.2.0。
