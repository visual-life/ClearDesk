# ClearDesk 2.3.4

## 1. 快捷控制：托盘图标改成「点进去再看」的一页（和音量合成器一样）

2.3.3 把托盘图标做成了主页面上一排小方块，太小、不好看。2.3.4 改了：

- 主页面上那排小图标没有了，换成一行「托盘图标 · N 个图标 ›」入口（和「声音」同一套按钮样式），点进去是一页单独的列表，窗口大小不变，滑动 / 淡入淡出和音量合成器一样，左上角 ← 返回。
- 这一页和音量合成器同样的版式：顶部 ← 返回 + 标题「托盘图标」+ 右边刷新按钮；每个图标一行：28 px 的图标（放大用高质量缩放）、应用名、状态文字（比如「已连接」）、被收起的图标标「收起」、右边一个「…」按钮；整行悬停高亮；图标多了滚动（不显示滚动条），没有图标时显示提示；底部「打开系统任务栏设置（托盘图标）」链接。
- 整行左键 = 该图标的左键（通常是打开主窗口），整行右键或「…」 = 该应用自己的右键菜单，双击 = 双击。
- 设置 → 桌面组件：「快捷控制里显示托盘图标入口」（默认开）和「托盘图标范围」（全部 / 仅被收起的 / 仅任务栏上可见的）保留。关掉后入口和页面消失，快捷控制回到原来的 285 px 高；开着时是 329 px（多出的 44 px 就是这一行入口）。你自己拖过的窗口大小不会被改。
- 页面打开时每 2 秒读一次任务栏上的图标；页面关着时每 10 秒读一次，只用来更新入口上的数字。第一次打开页面时自动读一次被收起的图标，之后点右上角刷新再读。

## 2. 右键不再把任务栏弹出来

以前右键是真的在图标上点一下鼠标，任务栏被「完全隐藏」时就得先把它弹出来。现在改成：

- **右键**：用 Windows 自己的 UI Automation `ShowContextMenu`（`IUIAutomationElement3`）。系统把这次右键原样交给应用，应用弹出自己的菜单，不用鼠标、不移动指针、任务栏不会出来。已验证对「被收起的图标面板里的图标」和「任务栏本身上的图标（任务栏被完全隐藏时）」都有效。
- **左键 / 双击**：仍然是 UI Automation 的 Invoke（本来就不需要鼠标）。
- 只有在系统拒绝 `ShowContextMenu`（比如以后 Windows 改了任务栏）时，才回到老办法（在图标上真点一下，会把任务栏临时弹出来），并在日志 / 测试里记为「mouse click (fallback)」。
- 菜单出现的位置由应用自己决定，多数应用会放在鼠标指针处；你点的是 ClearDesk 里的那一行，所以菜单就出现在那一行旁边。点了之后 ClearDesk 先允许任何程序把窗口带到前台（AllowSetForegroundWindow），让菜单能正常获得焦点、点别处能正常关掉。

## 3. 读取被收起的图标不再闪一下

以前读被收起的图标要把「显示隐藏的图标」面板展开一下，屏幕上会闪一下。现在：

- 面板展开的同时给它一个空的窗口区域（SetWindowRgn），所以屏幕上什么都不画；读完 / 用完以后再还原成正常形状，你自己点开隐藏图标面板时不受影响。ClearDesk 启动和退出时还会检查一次，不会留下「空白面板」。
- 图标图片只能从屏幕上真正显示的像素复制。某个图标还没有图片时，会让面板真的显示一次（短暂闪一下，每个图标只一次）把图片记下来，之后再读就不会闪。图片保存在 `tray-icons.json`。
- 读取时面板仍然会短暂抢一下键盘焦点（系统的行为）。

已知限制：①读取时 Windows 有时会在面板位置显示一个很小的提示框（图标名字）；②菜单位置由应用决定；③复制不到图片的图标显示首字母；④多显示器只读主任务栏；⑤Windows 更新改变任务栏结构（类名 / AutomationId）后，读取会失效，区域显示「没有托盘图标」，其它功能不受影响。
