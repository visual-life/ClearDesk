# ClearDesk 2.0.3

发布日期：2026-10-22。维护者：visual-life。

## 变更

- 新增“组件管理”页（设置侧栏“关于”下方）：一处列出全部组件实例——时钟、天气、音乐、日历、黄历、性能，每张便签（显示首行预览和字数），每个收纳格（名称和项目数）。每项显示状态（显示中／已关闭／已锁定），可“显示／关闭”“定位”（把组件短暂置顶，边框闪烁并提示“在这里”）和“删除”；收纳格名称可直接在列表里改，组件标题实时同步。页面上方有“新建组件”按钮。
- 区分“关闭”和“删除”：关闭只从桌面隐藏，内容、位置和设置都保留，可随时重新显示（便签现在也可以只关闭不删除，重启后保持隐藏）。删除前会弹窗写明会丢失什么（便签全部文字；收纳格的项目引用、名称和位置；单个组件的位置、尺寸、材质和锁定设置）。删除收纳格只移除引用，原文件和文件夹不受影响。收纳格右键菜单也新增“删除收纳格”。
- Dock 点击与任务栏一致：应用窗口已在最前面时，点击 Dock 图标会把它最小化（遵循“窗口最小化动画”设置）；已最小化或在其他窗口后面时恢复并切到前台；多窗口应用仍切到最近使用的窗口。点击 Dock 会先激活 Dock 自己，所以改用 WinEvent 前台事件记录点击前的前台窗口（忽略 ClearDesk 自己的窗口）。QQ 这类关闭后缩到托盘的应用，没有可见窗口时点击会重新启动它，由应用自己恢复主窗口。
- Dock“窗口遮挡时自动隐藏”（设置 → Dock 栏，默认关）：其他应用的可见、未最小化窗口与 Dock 区域重叠时，Dock 向下滑出屏幕；鼠标移到屏幕底部边缘（Dock 的水平范围内）即可唤出，移开约 0.5 秒后若仍被遮挡就再次隐藏；遮挡结束后自动回来。忽略 ClearDesk 自己的窗口、桌面、任务栏、工具窗口和被隐藏（cloaked）的窗口；全屏窗口仍由原来的逻辑整体隐藏 Dock。用 WinEvent 钩子（前台、最小化／还原、窗口移动），合并 150 ms 后才检查一次，CPU 占用很低；按 Dock 所在显示器的 DPI 换算坐标。
- 版本号统一为 2.0.3。

## 说明

- “删除”无法撤销；只想暂时隐藏请用“关闭”。
- “窗口遮挡时自动隐藏”只看 Dock 所在区域，其他显示器上的窗口不影响。
- 完整功能见 [2.0.2](2.0.2.md)、[2.0.1](2.0.1.md)、[2.0.0](2.0.0.md) 更新说明。
