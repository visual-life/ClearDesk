# ClearDesk 2.0.4

发布日期：2026-10-22。维护者：visual-life。

## 变更

- 新增“快捷控制”组件（单实例；可从桌面右键“ClearDesk 新建组件”（含 Windows 11 一级菜单）、组件右键、托盘菜单和设置 → 组件管理中添加；材质、锁定、磁吸与其他组件一致）：
  - 音量：滑块（支持拖动和滚轮）与静音按钮，直接控制默认输出设备（Core Audio IAudioEndpointVolume）；在系统或其他程序里调节音量、静音或切换默认设备时，组件通过回调即时更新。显示当前设备名，点击设备名可在菜单中切换默认输出设备（失败时打开声音设置）。
  - WLAN：开关通过 Windows.Devices.Radios 控制无线网卡；显示已连接的网络名和信号格数；点击文字打开 WLAN 设置，“可用网络”按钮打开系统网络面板。
  - 蓝牙：开关同样通过 Radios 控制，显示已连接设备数量（悬停可看设备名）；点击文字打开蓝牙设置。
  - 快捷入口：设置、显示、声音、可用网络。
  - 没有无线电权限时显示说明，点击打开“隐私 → 无线电”；没有对应适配器时提示“未找到适配器”。
  - 全部基于事件（音量回调、默认设备变化、无线电状态变化、网络状态变化、蓝牙设备监视器），只有信号格数每 20 秒且组件可见时刷新一次。
- 版本号统一为 2.0.4。

## 说明

- 切换默认输出设备使用 Windows 声音面板同样使用的系统接口（未公开文档）；若某些系统上失败，会改为打开声音设置。
- 在 Windows 11 24H2 等系统上，读取 WLAN 网络名可能需要允许“位置”权限；没有权限时显示“已连接”或配置文件名。
- 完整功能见 [2.0.3](2.0.3.md) 更新说明。
