# ClearDesk 1.6.2 — Dock 实时磨砂与菜单修复

维护者：visual-life。相较 GitHub 上的 1.6.0，本版集中修复 Dock 材质和右键菜单；设置窗口仍沿用旧版布局。

## 更新了什么

- **Dock 可选玻璃或磨砂**：右键 Dock 背景空白处 → 材质设置，可选“玻璃 · 实时清透”和“磨砂 · 实时模糊”。选择保存后重启继续使用。
- **后方画面实时变化**：磨砂采样真实窗口内容，移动窗口、切换页面时背景同步变化，不再显示一张固定壁纸；应用图标保持清晰。
- **修复黑底和方形底板**：使用 Windows 合成器背景层和圆角几何遮罩，消除先前测试版本的黑色块、灰色矩形及圆角外溢。
- **同步显隐和尺寸**：背景层跟随 Dock 移动、悬停放大、应用退出收拢和全屏隐藏；切回玻璃或关闭 Dock 时释放。
- **统一右键菜单和二级菜单**：深色圆角、可读文字、悬停高亮、选中标记和子菜单箭头，修复白底白字。

1.6.1 是本地过渡版本，曾强制 Dock 使用透明玻璃；1.6.2 恢复了两种材质选择。此处已包含 1.6.1 的菜单修复，不需要先安装 1.6.1。

## 验证和限制

- 105 项本地回归检查、17 项基础自检通过。
- 本机 Windows 11 检查了背景透色、圆角、玻璃／磨砂切换和 Dock 显隐；Windows 10 兼容路径尚未真机验证。
- Windows 透明效果及电源策略可能影响模糊效果。不支持模糊接口时仍可用玻璃。
- 本版改变的是 Dock。桌面收纳框保留壁纸磨砂，启动台保持实时透明；音乐客户端兼容范围与 1.6.0 一致。

## 下载与升级

下载附件 `ClearDesk-1.6.2-windows-x64-with-source.zip`。Windows x64、.NET Framework 4.8；外部音乐连接需要 Windows 10 1809 或更新版本。

退出旧版，完整解压到新目录，保留 `taskbar` 文件夹后运行 `ClearDesk.exe`。原有 `%LOCALAPPDATA%\ClearDesk` 配置继续使用。1.6.1 用户升级后可重新选择磨砂；不要同时运行两个版本。

若希望使用新版浅色设置界面，请直接下载 [1.7.0](https://github.com/visual-life/ClearDesk/releases/tag/v1.7.0)，它包含本版全部修复。快捷方式或开机启动仍指向旧目录时，需要更新到新位置。

附件包含程序、对应源码、测试记录和可选官方 TranslucentTB 组件及许可证，不含用户配置。`source-commit.txt` 记录源码提交，`SHA256SUMS.txt` 为包内逐文件校验，Release 附件 `ClearDesk-1.6.2-SHA256.txt` 用于核对下载 ZIP。
