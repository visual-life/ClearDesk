# ClearDesk 2.2.6 发布说明（2026-11-01）

## 文件夹映射：新增列表视图

列表视图像资源管理器一样，竖着一行显示一项。

- **每一行**：18 px 小图标加文件名。文件夹在前，按自然顺序排列。名称只占一行，太长时用省略号结尾，完整名称可以悬停查看。
- **切换视图**：右键菜单新增「视图：列表 / 图标」。每个组件实例分别保存视图（`widgets\folder*.json` 里的 `View`）。
- **默认视图**：
  - 新建的文件夹映射组件默认用列表视图。
  - 2.2.5 已经选好文件夹的组件保持原来的图标视图，可以从右键菜单切换。
- **随组件缩放**：行高（26）、字号（12.5）、图标（18）都跟着组件缩放。实测把组件放大到 1.6 倍，行高从 26 变成 41.6。每一行始终占满组件宽度，调整宽度后自动跟随。
- **操作**：鼠标悬停时高亮，双击打开，滚轮滚动，不显示滚动条。
- **原有功能都保留**：自定义背景、无边框、多开、实时更新（FileSystemWatcher）、每一项的右键菜单（打开 / 在资源管理器中显示 / 复制路径）。
