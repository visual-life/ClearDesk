# ClearDesk 2.3.3

## 1. Dock 应用提醒闪烁

应用有变化时（任务栏按钮会闪烁，例如聊天软件来了新消息、下载完成、需要确认），Dock 里对应的图标现在会跳动并亮起橙色光晕，直到你切换到这个应用或它关闭。

**以前有没有这个功能？** 没有。查过当前源码、git 历史、`backup-before-2xx` 各份备份和所有旧版本的源码：Dock 从来没有处理过任务栏闪烁（FlashWindowEx / HSHELL_FLASH）。唯一叫 `Flash()` 的代码是「组件管理 → 定位」让组件闪一下（2.0.3 起），和 Dock 无关；Dock 上的小圆点只表示「正在运行」。所以不是功能被去掉了，而是一直没有。

- 实现：注册 Windows 外壳钩子（`RegisterShellHookWindow` + `SHELLHOOK` 消息），收 `HSHELL_FLASH`（0x8006，开始闪烁）、`HSHELL_REDRAW`（6，不再闪烁）、`HSHELL_WINDOWACTIVATED` / `HSHELL_RUDEAPPACTIVATED`（4 / 0x8004，窗口被切到前台）和 `HSHELL_WINDOWDESTROYED`（2）。外壳钩子由 Windows 直接发给 ClearDesk，不经过任务栏，所以**任务栏被「完全隐藏」时同样有效**。
- 匹配：先按 Dock 自己的窗口列表（窗口句柄）匹配，再按程序路径 / 包标识（AUMID）匹配；固定且正在运行的项目、尚未进入 Dock 列表的新窗口、UWP（ApplicationFrameHost 的框架窗口）都能对上。窗口有 owner 时按顶层 owner 算。
- 动画：图标后面一个径向渐变的橙色光晕（带位图缓存，只改透明度，不逐帧重排），0.7 秒一个来回的正弦呼吸 + 开头弹跳三次；约 12 秒后停在稳定的亮光上（不再动，但一直亮着），直到你切换过去或应用关闭。系统关闭了动画效果（「显示动画」）时直接用稳定亮光。
- 自动隐藏的 Dock：默认**不**弹出（避免打扰），下次你把鼠标移到屏幕底边唤出 Dock 时就能看到仍在闪的图标。可以在设置里打开「提醒时唤出 Dock」：有应用提醒就把 Dock 滑出来 4.5 秒再自动收回。
- 设置 → Dock 与启动台：「应用提醒闪烁」（默认开）、「提醒时唤出 Dock」（默认关）。
- 正在前台的窗口不会闪；ClearDesk 自己的窗口不会触发。

## 2. 快捷控制里的「托盘图标」

针对「右下角收起来的图标每次关应用 / 开应用都要去那边点一下」：快捷控制组件底部新增「托盘图标」区域，列出任务栏右下角通知区域的所有图标（包括被收进「显示隐藏的图标」里的），不用任务栏也能管理后台应用。

- 左键 = 对应图标的左键（通常是打开主窗口）；右键 = 该应用自己的右键菜单（例如「退出」）；双击 = 双击。鼠标悬停显示应用的提示文字。
- 图标多了：默认一行，右上角的 ⌄ 展开成最多四行的网格（再多可滚动）。
- 任务栏上可见的图标每 2 秒读取一次，增删实时更新；被收起的图标需要「展开」任务栏的隐藏面板才能读到，会短暂闪一下并抢一下焦点，所以**只在你点右上角刷新按钮时读取**，结果（名称和图标图片）保存在 `tray-hidden.json`，重启后立即显示。点了一个已退出的应用，会提示并把它从列表里去掉。
- 设置 → 桌面组件：「快捷控制里显示托盘图标」（默认开）、「托盘图标范围」（全部 / 仅被收起的 / 仅任务栏上可见的，默认全部）。关闭后快捷控制回到原来的大小。
- 实现：Windows 11（XAML 任务栏）没有旧版 ToolbarWindow32，也不给其他程序图标句柄和回调消息，所以用 UI Automation 读取 / 操作：任务栏上的图标是 `Shell_TrayWnd` 下的按钮，隐藏的图标通过「显示隐藏的图标」面板读取；左键用 InvokePattern，右键是对该图标中心发一次真实的鼠标右键（鼠标随后放回原处），应用因此弹出自己的菜单；图标图片在图标真正显示在屏幕上时从屏幕复制（UI Automation 不提供图片），复制不到时显示首字母。
- 任务栏被「完全隐藏」时：隐藏面板里的图标照常读取、点击（面板是独立窗口，不受影响）；任务栏上可见的图标左键（Invoke）照常，右键会让任务栏临时露出 5 秒再点。任务栏被收起时无法从屏幕上复制图标图片（Windows 会如实告知被收起的区域上没有这个窗口），这些图标先显示首字母，任务栏显示过一次（例如按 Windows 键）后自动换成真实图标，并记在 `tray-icons.json`。
- 为什么不点屏幕：右键前会确认目标位置上的窗口确实是托盘窗口（被收起的任务栏、被别的窗口挡住的图标都不会被点到）。

已知限制：①图片是复制屏幕得到的，未显示过的图标先用首字母占位；②双击是连续两次点击，要求真正 WM_LBUTTONDBLCLK 的应用可能不响应；③读取隐藏图标时 Windows 的隐藏面板会闪一下；④多显示器上只读主任务栏；⑤Windows 更新改变任务栏结构（元素类名 / AutomationId）时读取会失效，此时区域显示「没有托盘图标」，其它功能不受影响。

## 其他

- 新增 `--flash-helper` / `--tray-helper` 两个只给测试用的辅助模式（单独的小程序：一个离屏窗口调用 FlashWindowEx；一个带自己托盘图标的程序），不会被当成「另一个 ClearDesk」。
- 版本号统一为 2.3.3。外壳右键菜单包未改动（2.2.9.0），无需重新「一键启用」。
