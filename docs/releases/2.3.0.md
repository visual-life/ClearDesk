# ClearDesk 2.3.0

- 新增「完全隐藏任务栏」（设置 → 任务栏与窗口，托盘菜单也可切换；默认关闭）。
  - 开启后顶部任务栏完全收起，鼠标移到屏幕边缘也不会唤出。
  - 只有按下 Windows 键或 Ctrl+Esc 打开开始菜单 / 搜索时才显示，关闭后再次收起；显示期间鼠标停在任务栏上、或从任务栏打开的托盘弹窗 / 跳转列表在前台时不会收回。
  - 不安装键盘钩子、不拦截任何按键：以开始菜单 / 搜索成为前台窗口作为信号。通知、Alt+Tab 不受影响。
  - 工作区、副屏任务栏、TranslucentTB 兼容、退出和崩溃恢复，沿用原有的顶部任务栏自动隐藏机制。
- 桌面收纳新增「贴边隐藏」（每个收纳格右键单独开启，默认关闭）。
  - 收纳格拖到屏幕左、右、上、下边缘（14 px 以内）后自动缩进，只露出 6 px 细条。
  - 鼠标移到细条上平滑滑出；移开 600 ms 后滑回。拖动、打开右键菜单、往里拖文件时不会收回。
  - 保存的始终是展开后的位置；滑动不会触发位置保护（PositionGuard），也不会写入设置。
  - 与另一块显示器相邻的边不会触发，避免滑到另一块屏幕上；靠任务栏一侧会缩到任务栏后面。
- 版本号统一为 2.3.0。
