# ClearDesk 2.0.1 — Windows 11 一级桌面菜单、启动台材质

维护者：visual-life。本地交付，尚未发布到 GitHub。包含 2.0.0 全部功能。

## Windows 11 一级桌面右键菜单

Windows 11 的新式右键菜单第一层，只显示带包标识的 IExplorerCommand 扩展。2.0.1 随附：

- `ClearDeskShell.dll`：C++ 实现的 IExplorerCommand。根项为“ClearDesk 新建组件”（ClearDesk 图标），子项由 IEnumExplorerCommand 列出：便签、桌面收纳格、时钟、天气、音乐、日历、黄历 / 农历、性能。点击后启动同目录的 `ClearDesk.exe --new-widget <类型>`；ClearDesk 已在运行时，由命名管道转交给正在运行的实例。
- `ClearDeskShell.msix`：稀疏包，只含清单和图标。清单通过 desktop4:FileExplorerContextMenus 为 `Directory\Background` 注册菜单，并用 com:SurrogateServer 注册 COM 类。外部位置即 ClearDesk 所在文件夹。
- `ClearDeskShell.cer`：签名用的自签名证书（只含公钥）。

### 安装

运行同目录的 `install-menu.ps1`（右键 → 使用 PowerShell 运行），或在 ClearDesk 设置 → 外观与材质 →“Windows 11 一级菜单”点“安装 / 修复”。

- **管理员**：首次安装需要把证书导入“本机\受信任人”，会弹出一次 UAC。已实测：只导入“当前用户\受信任人”时，Windows 拒绝安装（0x800B0109，根证书不受信任）。之后重装或修复不再需要管理员。
- **开发者模式**：开启开发者模式本身也需要管理员，而且松散布局注册不适合发给普通用户，因此没有采用。
- **移动文件夹**：移动 ClearDesk 文件夹后，需要重新运行 install-menu.ps1，因为外部位置是安装时记录的路径。
- **卸载**：运行 `uninstall-menu.ps1`；加 `-RemoveCertificate` 参数会一并移除证书，这一步需要 UAC。

### 显示与隐藏

设置中的“Windows 11 一级菜单显示”开关写入 `HKCU\Software\ClearDesk\ModernMenu`，外壳扩展每次弹出菜单时读取，立即生效。关闭“桌面右键新建组件”时，一级菜单和经典菜单都会隐藏。

经典菜单（显示更多选项）继续保留，Windows 10 使用它，也作为后备。

## 启动台材质

- 右键启动台空白处 → 材质设置：玻璃 · 实时清透／磨砂 · 实时模糊，当前项打勾。
- 设置 → Dock 栏 →“启动台材质”与右键菜单同步，并保存在设置中。
- 磨砂与 Dock 使用同一套合成器实时模糊（HostBackdrop）：在启动台后方放一个不接收点击的模糊窗口，裁剪为同样的圆角。后方窗口的文字会被模糊，不再透出。从 2.0.0 及更早版本升级时，启动台默认改为磨砂。

## 验证（本机 Windows 11 26H2 26300，2026-10-22）

- 自签名证书导入“本机\受信任人”后，Add-AppxPackage -ExternalLocation 安装成功。桌面右键第一层出现“ClearDesk 新建组件”，展开后显示 8 种组件（见截图）。
- 只导入“当前用户\受信任人”时失败：0x80073CF0／0x800B0109。
- 自检、回归（新增启动台材质 7 项、一级菜单默认值 1 项，并把旧的“启动台只用透明”断言改为新的磨砂行为）、客户端歌词、LRCLIB 联网测试全部通过。

## 限制

- 首次安装一级菜单需要一次管理员授权（UAC）。
- 证书为本机生成的自签名证书。分发给其他电脑时，对方需要信任这张证书，或者改用受信任的代码签名证书。
- 子菜单在 2.0.0 经典菜单中“桌面收纳格”后有分隔线；Windows 11 一级菜单的子项之间不显示分隔线（系统忽略该标志）。
