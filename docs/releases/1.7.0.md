# ClearDesk 1.7.0 — 全新浅色设置界面

维护者：visual-life。1.7.0 包含 1.6.2 的全部 Dock／菜单修复，并将原来的深色长列表设置重做为苹果风格的浅色分类界面。

## 两个版本分别更新了什么

| 版本 | 主要变化 |
| --- | --- |
| **1.6.2** | Dock 玻璃／实时磨砂切换、真实背景采样、黑底与矩形边角修复、背景同步显隐和尺寸、深色圆角右键与二级菜单 |
| **1.7.0** | 全新浅色设置窗口、六个分类、跨分类搜索、统一开关／滑块／下拉菜单、固定底部操作栏，设置内直接选择音乐来源和 Dock 材质 |

从 1.6.0 升级时**直接安装 1.7.0 即可**，无需逐个安装中间版本。完整的 Dock 修复说明见 [1.6.2 发行说明](https://github.com/visual-life/ClearDesk/releases/tag/v1.6.2)。

## 1.7.0 新界面

- **浅色卡片与柔和蓝色侧栏**：更清晰的标题、分组、细边框和蓝色开关；保留原有应用图标与 Windows 窗口控制。
- **六个分类**：通用、桌面收纳、Dock 栏、音乐组件、外观与材质、关于。原有启动、桌面图标、窗口动画、天气与组件设置均保留。
- **设置搜索**：跨分类查找，有无结果提示；切换分类不会丢失正在调整的值。
- **统一控件**：开关、滑块和播放器／城市／材质下拉框使用同一套浅色样式；桌面组件的深色右键菜单保持原样。
- **固定底部操作栏**：恢复桌面图标、收起到托盘、应用设置。窗口缩小时内容独立滚动；“退出并恢复”在“关于”页。
- **集中选择来源和材质**：在设置中选择音乐播放器，以及 Dock 的玻璃或实时磨砂，点击应用更新组件。
- **保留原有配置**：设置保存格式和位置不变；此次不改变 Dock 动画与音乐连接实现。

## 下载与升级

下载附件 `ClearDesk-1.7.0-windows-x64-with-source.zip`，完整解压后运行 `ClearDesk.exe`。需要 Windows x64 和 .NET Framework 4.8；外部音乐连接需要 Windows 10 1809 或更新版本。

1. 从旧版托盘菜单或设置中退出 ClearDesk。
2. 解压到新文件夹，保留包内的 `taskbar` 文件夹，不要在 ZIP 内直接运行。
3. 启动新版本，原有 `%LOCALAPPDATA%\ClearDesk` 配置自动继续使用。
4. 若快捷方式或开机启动仍指向旧目录，更新到新位置；开机启动可在新版“通用”中关闭再开启。

双击托盘图标打开设置。组件、来源、材质调整后点击“应用设置”。关闭设置窗口后程序继续运行；退出并恢复桌面请到“关于”页或托盘菜单。
