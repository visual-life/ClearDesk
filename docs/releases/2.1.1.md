# ClearDesk 2.1.1 发布说明

发布日期：2026-10-25

## 天气组件：更稳定，并显示到区县

### 问题的原因

- 以前的天气只有一条链路：IP 定位服务 ipwho.is → 天气源 Open-Meteo，两者都是境外服务，在国内网络里经常超时或被拦；任何一环失败就显示「自动天气暂不可用」，也没有缓存可以显示。
- 使用 Clash / Mihomo 等代理（系统代理或 TUN）时，境外的 IP 定位服务看到的是代理出口（例如美国），于是曾把城市显示成「華盛頓哥倫比亞特區」。
- 以前的位置只到城市，国内 IP 定位本来也只有城市级精度。

### 现在怎么取天气

1. **位置**（按顺序，前一步成功就不再往下）：
   1. 手动选择的区县（设置里可搜索选择，不联网定位）。
   2. 上次成功的位置（Windows 定位 3 小时内、IP 定位 6 小时内有效）。
   3. **Windows 定位服务**（Wi-Fi / GPS，可到街道级，不受代理影响；需要在 Windows 设置 → 隐私和安全性 → 位置 中允许桌面应用访问位置）。
   4. **IP 定位**：同时问多个服务并投票——太平洋电脑网 pconline、ipip.net、哔哩哔哩（国内三个优先）；国内服务有结果时不再请求 ipwho.is、ip-api.com。中国时区的电脑上忽略境外结果（视为代理出口）。IP 定位只能到城市级，见「局限」。
   5. 以上都失败时沿用上一次的位置。
2. **区县名称**：用坐标做反向地理编码（BigDataCloud，失败时 OpenStreetMap Nominatim，中文）得到省、市、区县，只显示区县级名称：「呼和浩特市赛罕区」→ 赛罕区，「上海市黄浦区」→ 黄浦区；县级市、县、旗显示它自己的名称（如 土默特右旗）；没有区县的城市显示市名。名称统一为简体并去掉省/市前缀（區→区、華盛頓→华盛顿）。
3. **天气来源**（国内：腾讯天气 → Open-Meteo → met.no → wttr.in；国外：Open-Meteo → met.no → wttr.in）：均无需密钥。第一个来源超过 3.5 秒还没回答，就同时启动下一个（先到先用，慢的被取消）；单次请求最长 8 秒。天气按区县的坐标 / 名称查询。腾讯天气不认识某些旗县名称时，自动改用所属城市的数据，来源标注为「腾讯天气（市级）」。
4. **缓存**：最后一次成功的天气和位置保存在 `%LOCALAPPDATA%\ClearDesk\weather-cache.json`（只存取整后的坐标和地名，不存 IP 地址）。联网失败时组件继续显示这份数据并注明「更新于 HH:mm」，不再出现错误卡片；只有从未成功过时才显示错误提示。
5. **刷新节奏**：正常每 20 分钟一次；失败后按 1、2、4、8、15 分钟指数退避（带随机抖动）；网络切换、从睡眠恢复时立即刷新；窗口关闭时取消网络请求。HTTP 请求遵循系统代理设置。
6. 组件底部小字显示数据来源和位置来源（Windows 定位 / 网络 IP / 手动选择）；布局、调整大小、多日预报行不变。

### 设置（设置 → 外观与材质 → 天气）

- 自动天气（联网）开关：与以前一样，默认关，需要主动开启。
- 使用 Windows 定位：默认开；关闭后只用 IP 定位。
- 所在地：显示当前位置和来源，「重新定位」立即重新定位并刷新。
- 手动选择区县：输入「赛罕区」「黄浦区」等搜索，从结果里选择；「恢复自动」回到自动定位。手动选择不做 IP / Windows 定位。

### 局限

- **IP 定位只能到城市级，有时还是运营商登记的城市，不是你所在的城市**（例如本机 IP 被几个服务一致识别为包头，Windows 定位则给出具体的旗县）。想要准确的区县，请开启 Windows 定位，或在设置里手动选择。
- Windows 定位需要系统位置服务打开；台式机没有 GPS / Wi-Fi 时精度较差，可能取不到。
- 腾讯天气接口无需密钥，但不是公开文档的接口，将来可能变化——所以保留了三个备用来源；wttr.in 只有 3 天预报。
- 反向地理编码和搜索使用境外的 BigDataCloud / Nominatim（有请求频率限制），只在位置变化时调用并缓存结果。
- 请求只带 User-Agent `ClearDesk/版本号`，不发送设置或文件信息；查询会把取整后的坐标（约 1 公里）发给上述服务。

### 诊断

`ClearDesk.exe --weather-diag [输出文件] [轮数]` 依次测试 Windows 定位、各 IP 服务、反向地理编码、各天气来源和完整流程，写出诊断报告；不修改设置和缓存，不影响正在运行的 ClearDesk。

### 其他

- 修复 .NET Framework 把 deflate 压缩的响应读错的问题（Open-Meteo 曾报「块的长度与它的补集不匹配」）：现在只协商 gzip。
- 版本号统一为 2.1.1；在线更新测试脚本 `scripts/test-update.ps1` 不再写死版本号。
