# ClearDesk 1.6.0

发布日期：2026-10-20。维护者：visual-life。

本次更新重点是音乐组件。相较 1.5.2，新增桌面音乐客户端连接、定向播放控制和网易云兼容模式，并重新设计播放器菜单和卡片。原有磨砂收纳、动态 Dock、关闭应用动画和实时透明启动台继续保留。

## 新增和改进

- **音乐客户端连接**：通过 Windows 系统媒体会话读取歌名、歌手、封面、播放状态和进度；支持自动选择，或指定 QQ 音乐、网易云音乐、酷狗音乐。
- **定向播放控制**：上一首、播放／暂停、下一首只发送给卡片当前选择的客户端；自动模式优先正在播放的音乐客户端，不接管浏览器视频。按钮根据客户端能力启用。
- **网易云兼容模式**：对没有发布系统媒体会话的网易云 3.1.1，通过公开的无障碍播放控件读取歌曲信息并调用播放按钮。支持最小化后切歌，不发送全局媒体快捷键，不抢占焦点。
- **重新设计音乐卡片**：默认白色下拉框替换为深色圆角菜单；增加选中状态、圆角封面、细进度条、时间显示和图形控制按钮，使界面与桌面材质一致。
- **异步刷新与状态处理**：约每 0.75 秒异步刷新，切换来源后忽略过期结果；读取期间的控制请求等待处理，断开后清除旧歌曲，拒绝操作时显示提示。
- **保留本地播放**：仍可选择本地音乐、控制播放和音量，播放器选择会保存。

## 兼容范围

- 外部音乐连接需要 Windows 10 1809 或更新版本。先在客户端登录并播放歌曲；如有系统媒体控制设置，需要开启。ClearDesk 不需要音乐平台账号、密码或 API 密钥。
- 客户端提供什么媒体信息，卡片才能显示什么；不提供封面或时长时使用占位图或 `--:--`。
- 网易云兼容模式**没有专辑封面**；进度取自客户端公开文本，客户端最小化后停止刷新文本时，进度可能暂时停住。歌名和切歌仍可工作。
- 网易云兼容模式需要保留主窗口；完全关闭到托盘或后续版本改变界面结构时可能不可用。其他通过系统媒体会话连接的客户端，需保留该会话。
- 菜单中列出客户端不代表其所有历史版本都已验证。登录、会员及歌曲播放权限由客户端决定。

更多连接说明见 [音乐连接说明](https://github.com/visual-life/ClearDesk/blob/v1.6.0/docs/MUSIC.md)。

## 下载与升级

下载 Release 附件 `ClearDesk-1.6.0-windows-x64-with-source.zip`，完整解压后运行 `ClearDesk.exe`。需要 Windows x64 和 .NET Framework 4.8；外部音乐连接另需上述系统版本。普通使用不需要安装 SDK。

升级前从旧版本设置或托盘菜单退出，解压到新文件夹，保留包内 `taskbar` 文件夹，避免同时运行两个版本。已有设置位于 `%LOCALAPPDATA%\ClearDesk`，会继续使用；如果原快捷方式仍指向旧文件夹，请改为新版本。

在设置中开启“音乐控制与本地播放”，点击卡片右上角选择播放器即可使用。

发行包包含程序、完整 ClearDesk 源码、本地回归记录，以及可选的官方 TranslucentTB 组件、对应源码和许可证；不包含用户配置、账号资料或私人播放列表。`source-commit.txt` 记录包内源码提交，`SHA256SUMS.txt` 提供逐文件校验；Release 的 `ClearDesk-1.6.0-SHA256.txt` 用于核对 ZIP。

从源码构建另需 Windows 10/11 SDK（17763 或更新）；SDK 元数据仅用于编译，不随发行包分发。
