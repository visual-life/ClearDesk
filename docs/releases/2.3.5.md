# ClearDesk 2.3.5

2.3.5 修的是 2.3.4 里两个严重问题：关掉 ClearDesk 之后，任务栏右下角「^ 显示隐藏的图标」点了没反应；桌面上所有图标都不见了。

## 1. 「^」隐藏图标面板点了没反应

**原因**：2.3.4 为了读取被收起的图标时屏幕不闪，会给资源管理器的「隐藏图标」面板窗口设一个**空的窗口区域**（SetWindowRgn），读完再还原。如果读取过程中 ClearDesk 被关闭、被结束进程，或者你自己恰好在这时点了「^」，还原就没有发生，这个窗口一直带着空区域，之后你再点「^」，面板打开了但什么都画不出来。崩溃守护进程（--guard）当时只管桌面图标和任务栏，不管这个窗口。

**修复**：
- 彻底去掉这个办法：ClearDesk 不再给资源管理器的任何窗口改形状（任务栏「完全隐藏」用的区域是 2.3.0 就有的老机制，一直由守护进程负责还原，没有变）。代价：读取被收起的图标时，隐藏图标面板会短暂闪一下，和 2.3.3 一样。
- 启动、正常退出、守护进程善后时，都会检查「隐藏图标」面板窗口，如果带着空区域（2.3.4 留下的）就恢复成正常形状。已经碰到这个问题的用户，装上 2.3.5 并启动一次就好（或者重启电脑）。
- 右键隐藏图标之后，面板如果 9 秒后还开着，会像以前一样自动收起，不改窗口。

## 2. 桌面图标全部消失

**原因**：ClearDesk 自己显示/隐藏桌面图标用的是窗口的显示状态；Windows 自己的「显示桌面图标」开关（注册表 HideIcons）是另一套。两套不同步时，比如 ClearDesk 隐藏了图标，你（或系统）又在桌面右键 → 查看里点了「显示桌面图标」，Windows 的开关就变成「关」。2.3.1 起关闭 ClearDesk 时会「把图标显示出来，除非 Windows 的开关是关的」，于是看到开关是关的，就让图标一直藏着，桌面只剩壁纸。（没有找到 ClearDesk 自己写 HideIcons 的地方；现场确认过是 Windows 的开关为「关」，不是别的程序。）

**修复**：
- 每次运行开始时，记下 Windows 的开关是不是已经是「关」（你自己关的，会保留）。
- 如果开始时是「开」，那么 ClearDesk 退出时（托盘退出、设置里退出、更新重启、注销关机）和崩溃守护进程善后时，都会把图标显示出来，**并且**如果这时 Windows 的开关被关了，就把它重新打开（做法和桌面右键 → 查看 → 显示桌面图标完全一样，向桌面发同一个命令，不模拟键盘）。
- ClearDesk 改过图标之后，会写一个状态文件 `desktop-icons-state.json`，图标放回去后删除。下次启动时如果它还在（说明上次没来得及放回去，比如断电），而 Windows 的开关现在是「关」、并且上次开始时是「开」，就自动打开。
- 启动时还会处理已经不存在的旧会话留下的 recovery 文件（连守护进程一起被结束的情况）。正在运行的 ClearDesk 的文件不会动，也不会去结束任何任务栏程序。
- 托盘退出现在即使「保存/关闭窗口」出错，也一定会执行退出处理（恢复图标、任务栏、面板）。

## 其他
- 版本号统一为 2.3.5。外壳右键菜单包未改动（2.2.9.0），无需重新「一键启用」。
- 2.3.4 的「托盘图标」页面、直接右键（UI Automation ShowContextMenu，不弹出任务栏）都保留。
