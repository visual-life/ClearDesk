# 音乐连接

在 ClearDesk 设置中开启音乐组件。点击卡片右上角的播放器名称，选择自动、QQ 音乐、网易云音乐、酷狗音乐或本地音乐。

外部音乐连接需要 Windows 10 1809 或更新版本。先打开对应桌面客户端，在客户端内登录并开始播放。如果客户端有“系统媒体控制”或 SMTC 设置，需要开启。ClearDesk 不要求音乐平台账号、密码或 API 密钥，不会访问私人音乐接口。

## 显示与控制

每约 0.75 秒异步读取媒体会话。显示客户端提供的歌名、歌手、封面和进度；客户端不提供封面或时长时，显示占位图或 `--:--`。上一首、播放／暂停、下一首只针对当前显示的会话。

自动模式仅选择上述三类音乐客户端，优先正在播放的会话，不接管浏览器视频。指定客户端后，即使另一个程序正在播放，也不会自动切换过去。SMTC 模式下仅托盘运行仍可连接，但客户端必须保留系统媒体会话。

如果没有会话，组件显示连接提示；不支持的控制按钮禁用，客户端拒绝请求时显示提示。请在客户端使用含多首歌曲的播放列表测试切歌，播放权限、会员和登录限制仍由音乐客户端决定。

## 网易云桌面客户端兼容模式

**1.9.1 起：** 网易云 3.1.1 的内置浏览器界面默认不向 Windows 无障碍接口公开内容，此时只能从窗口标题读到“歌名 - 歌手”：组件仍显示歌名与歌词（滚动显示，无进度、无切歌）。右键音乐组件 →“以同步模式重启网易云”会关闭并以 `--force-renderer-accessibility` 参数重新打开网易云（会中断当前播放，需确认），之后即可读取进度、切歌与跳转。也可把该参数加到网易云快捷方式的“目标”末尾，长期生效。

本机网易云音乐 3.1.1 没有发布系统媒体会话，尽管已经启用系统媒体快捷键。ClearDesk 会自动使用其公开的 Windows 无障碍播放控件读取歌名、歌手与播放状态，并直接调用该客户端的上一首、播放／暂停、下一首按钮，不发送全局快捷键，也不抢占焦点。

此模式支持客户端最小化，但需保留主窗口；完全关闭到托盘或后续版本改变界面结构时可能不可用。兼容模式没有专辑封面，显示音符占位；进度取自客户端公开文本；1.9.1 在文本停滞时结合音频峰值推算进度，恢复后用真实读数校正，详见下文“最小化时的进度”。它不修改客户端文件，不注入进程，不读取登录资料。

## 开发依据

使用 Microsoft 官方 [GlobalSystemMediaTransportControlsSession](https://learn.microsoft.com/en-us/uwp/api/windows.media.control.globalsystemmediatransportcontrolssession) 接口。编译需要 Windows 10/11 SDK（17763 或更新）的 `Windows.winmd`，仅为编译引用，不随发行包分发；运行时由 Windows 提供接口。

## 歌词（1.8.2 起，1.9.1 更新）

点击音乐卡片右上角“歌词”，或在设置 → 音乐组件开启“显示歌词”。默认关闭。开启后在播放控制下方显示当前句与下一句，依据播放器提供的播放位置更新；暂停、跳转和切歌后会重新定位。1.9.1 会使用网易云兼容模式的本地进度估计驱动歌词，估计存在误差；无声段落或静音超过约 2 秒可能被判为暂停。

系统媒体接口没有歌词字段。现在优先读取 QQ 音乐或网易云已加载的本地歌词缓存，底部会标明“客户端歌词”。QQ 按缓存文件名中的曲目信息匹配并解码 QRC；网易云读取 playingList、queue、fmPlay、history 中必要的曲目元数据，匹配 ID 后读取 LRC。只读，不修改文件，不读取账号、密码或 Cookie，也不上传这些元数据文件。歌曲名、歌手、时长和可用专辑均需匹配，多个候选不猜测。

1.8.2 在客户端没有缓存时使用 LRCLIB；1.9.1 先尝试 QQ 音乐／网易云在线歌词，最后使用 [LRCLIB 公开接口](https://lrclib.net/docs) 匹配。LRCLIB 请求会将当前歌名、歌手、专辑及可用时长发送至该服务，服务也会收到网络连接的公网 IP。不发送账号、播放列表或登录信息。打开客户端歌词页可促使它加载歌词；ClearDesk 每 15 秒后台补查一次，命中后停止补查并自动换成客户端歌词。每个匹配保存在内存中，最多 64 个；没有额外复制用户歌词到发行目录。

默认目录：QQ 为 `%APPDATA%\Tencent\QQMusic\QQMusicCache\QQMusicLyricNew`，网易云为 `%LOCALAPPDATA%\NetEase\CloudMusic\webdata`。缓存移动、格式变更或无时长等信息时会回退。酷狗客户端缓存暂未接入，继续使用 LRCLIB 或手动导入。供应商收录可能不完整，匹配失败不代表播放器故障。

本地音频优先读取同目录的同名 `.lrc`，不会发送本地文件路径到服务端。也可右键音乐组件 → **导入当前歌曲歌词…**，选择 `.lrc` 或 `.txt`。导入关联保存在本机设置，原文件保留原位；支持 UTF-8、带 BOM 的 UTF-16 与 GB18030。没有时间轴或播放器没有提供时长／进度时，显示可滚动的普通歌词。

右键“重新匹配歌词”清除当前歌曲的导入关联及内存匹配后再读取。找不到歌词、纯音乐、网络不可用时显示对应状态，不显示上一首残留文本。歌词区可关闭，关闭会取消正在进行的请求。

当前验证包含自编示例歌词的显示、LRC 时间轴、暂停／回退、切歌、关闭、异步过期结果与菜单位置检查，以及公开示例歌曲的真实 LRCLIB 请求。1.8.2 增加 QQ／网易云各 3 首本机缓存的只读匹配和解析验证，以及缓存损坏、多义匹配、来源隔离、自动补读的回归检查。上述为 1.8.2 的验证范围；1.9.1 随附本机客户端实测记录见 [发行说明](releases/1.9.1.md)，未对所有歌曲与客户端版本逐一实测。歌词来自原提供方或用户导入，不随源码附带第三方歌曲全文。

## 进度跳转（1.9.1）

进度条改为自绘细线：平时 3 像素半透明，悬停加粗并显示小圆点，点击或拖动即可跳转；拖动期间及松开后约 2.5 秒内不被轮询覆盖。播放器不支持跳转或没有时长时变灰。

- 支持系统媒体会话跳转的播放器：调用 `TryChangePlaybackPositionAsync`。
- QQ 音乐（会话禁止跳转）：通过 UI Automation 找到客户端自己的进度条（两个时间标签之间），向其窗口发送一次点击，不移动鼠标、不抢焦点；被其他窗口遮挡也可用。
- 网易云（同步模式）：通过无障碍接口找到“播放进度调节”并同样发送点击。
- 播放器最小化时：临时把窗口设为几乎全透明并无激活恢复，点击后再无激活最小化，并恢复原样式与位置。网易云实测稳定；QQ 音乐在长时间最小化后可能仍使用旧布局而忽略点击，此时进度会回到原处，请把 QQ 音乐窗口还原一次（可在其他窗口之后）再试。关闭到托盘时不可用。
- QQ 进度条位置会按窗口尺寸记在 `%LOCALAPPDATA%\ClearDesk\qqmusic-seekbar.txt`，仅含坐标。

## 歌词来源与匹配（1.9.1）

查找顺序：手动导入 → 客户端本地缓存（QQ QRC／网易云 LRC）→ 当前播放器的在线歌词（QQ 音乐 `c.y.qq.com` 公开搜索与歌词接口，或网易云 `music.163.com` 公开接口）→ 另一家在线歌词 → LRCLIB。QQ／网易云在线请求发送歌名和歌手（及匹配到的歌曲 ID）；LRCLIB 还会接收可用专辑和时长。服务会收到网络连接的公网 IP；不发送账号、Cookie 或播放列表。

- 修复：部分 QQ QRC 缓存（如含未转义字符的英文歌词）不是合法 XML 导致整首读取失败，现在改为直接提取歌词内容。
- 模糊匹配：精确标题优先；否则去掉 (Explicit)、(feat. …)、[Remastered]、（伴奏）等括号后缀再比；多歌手只需任一歌手相同（主歌手相同加分）；时长越接近越优先，相差超过 8 秒视为不同版本。QQ 本地缓存的模糊匹配遇到并列最高分时不猜测。
- 网易云 3.x 的 webdata\lyric 目录在新版中可能不再写入；此时依赖在线歌词。

## 最小化时的进度（1.9.1）

网易云 3.x 最小化后，内置浏览器不再更新无障碍树：“mm:ss / mm:ss”文字与播放按钮冻结在最小化那一刻，刚切的歌会一直显示 0:00。ClearDesk 发现读数停滞（窗口最小化，或读数 1.6 秒不变）时改用本地计时（src/PlaybackEstimator.cs）：

- 起点：最后一次真实读数。
- 播放／暂停：网易云音频会话输出峰值（WASAPI IAudioMeterInformation，src/AudioPeak.cs）；连续 2 秒无声视为暂停，并回退到最后有声的位置。
- 切歌：窗口标题变化时从 0:00 开始，时长取自 %LOCALAPPDATA%\NetEase\CloudMusic\webdata\file\playingList。
- 校正：任何真实读数变化（恢复窗口、跳转、切歌时客户端刷新）立即覆盖推算值。不会为了读进度去恢复窗口。

## 诊断

`ClearDesk.exe --music-diag <输出文件> [src=qq|netease] [notree] [seek] [at=0.3] [watch=秒] [toggle]` 默认输出当前会话、歌词来源和界面结构；加 `seek` 时会真的把播放器跳到 `at` 指定比例；`watch` 每秒记录一次进度与音频峰值，`toggle` 会真的切换播放／暂停。
